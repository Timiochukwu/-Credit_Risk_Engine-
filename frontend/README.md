# Nigerian Credit Risk Engine - Frontend

React + TypeScript frontend for the Nigerian Credit Risk Engine.

## Features

- Modern React 18 with TypeScript
- Material-UI (MUI) components
- React Router for navigation
- React Query for data fetching
- Vite for fast development
- Responsive design

## Getting Started

\`\`\`bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
\`\`\`

## Pages

- **Login**: Authentication
- **Dashboard**: Overview metrics and KPIs
- **Loan Application**: Submit new applications
- **Portfolio**: Portfolio management
- **Analytics**: Advanced analytics and reporting

## API Integration

The frontend integrates with the FastAPI backend at `http://localhost:8000`

Default credentials:
- Username: admin
- Password: password123
