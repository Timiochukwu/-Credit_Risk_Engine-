## Understanding JWT (JSON Web Tokens)

**What is JWT?**
A JWT is a secure way to transmit information between client and server. It consists of three parts:

```
header.payload.signature
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjM0NTY3ODkwIn0.dozjgNryP4J3jVmNHl0w5N_XgL0n3I9PlFUP0THsR8U
```

**Why JWT?**
- Stateless (no server-side session storage)
- Secure (cryptographically signed)
- Contains user information (no database lookup needed)
- Industry standard for API authentication

**How it works:**
1. User logs in with username/password
2. Server validates credentials
3. Server creates JWT containing user info
4. Client stores JWT (e.g., in localStorage)
5. Client sends JWT with each request in `Authorization: Bearer <token>` header
6. Server validates JWT and processes request

## Step 4: Create Authentication Utilities

**File:** `src/utils/security.py`

```python
"""
Security utilities for password hashing and JWT tokens.
"""

from datetime import datetime, timedelta
from typing import Optional
from jose import JWTError, jwt
from passlib.context import CryptContext

from src.utils.config import settings

# Password hashing context
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")


def verify_password(plain_password: str, hashed_password: str) -> bool:
    """
    Verify a plain password against a hashed password.

    Args:
        plain_password: Plain text password
        hashed_password: Hashed password from database

    Returns:
        True if password matches, False otherwise
    """
    return pwd_context.verify(plain_password, hashed_password)


def get_password_hash(password: str) -> str:
    """
    Hash a password using bcrypt.

    Args:
        password: Plain text password

    Returns:
        Hashed password
    """
    return pwd_context.hash(password)


def create_access_token(data: dict, expires_delta: Optional[timedelta] = None) -> str:
    """
    Create a JWT access token.

    Args:
        data: Data to encode in the token (e.g., {"sub": "username"})
        expires_delta: Token expiration time (defaults to config value)

    Returns:
        Encoded JWT token
    """
    to_encode = data.copy()

    if expires_delta:
        expire = datetime.utcnow() + expires_delta
    else:
        expire = datetime.utcnow() + timedelta(minutes=settings.access_token_expire_minutes)

    to_encode.update({"exp": expire})
    encoded_jwt = jwt.encode(to_encode, settings.secret_key, algorithm=settings.algorithm)

    return encoded_jwt


def decode_access_token(token: str) -> Optional[str]:
    """
    Decode and validate a JWT token.

    Args:
        token: JWT token string

    Returns:
        Username from token, or None if invalid
    """
    try:
        payload = jwt.decode(token, settings.secret_key, algorithms=[settings.algorithm])
        username: str = payload.get("sub")
        return username
    except JWTError:
        return None
```

**Security Concepts Explained:**

1. **Bcrypt:** Hashing algorithm designed to be slow
   - Takes ~100-300ms to hash (makes brute-force attacks impractical)
   - Automatically salted (random data added to password)
   - Industry standard for password storage

2. **JWT Claims:**
   - `sub` (subject): Usually the username or user ID
   - `exp` (expiration): When the token expires
   - `iat` (issued at): When token was created

3. **Token Signing:** Uses SECRET_KEY to create cryptographic signature
   - Ensures token hasn't been tampered with
   - Only server can create valid tokens

## Step 6: Create Authentication Endpoints

**File:** `src/api/auth.py`

```python
"""
Authentication endpoints and dependencies.
"""

from fastapi import APIRouter, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from sqlalchemy.orm import Session
from datetime import timedelta

from src.utils.database import get_db
from src.utils.security import (
    verify_password,
    get_password_hash,
    create_access_token,
    decode_access_token
)
from src.utils.config import settings
from src.utils.logger import logger
from src.models.database_models import User, UserRole
from src.api.schemas import UserCreate, UserResponse, Token

router = APIRouter(prefix="/api/v1/auth", tags=["Authentication"])

# OAuth2 scheme for token authentication
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/v1/auth/login")


def get_user_by_username(db: Session, username: str) -> User:
    """Get user from database by username."""
    return db.query(User).filter(User.username == username).first()


def authenticate_user(db: Session, username: str, password: str) -> User:
    """
    Authenticate user with username and password.

    Returns:
        User object if authentication successful, None otherwise
    """
    user = get_user_by_username(db, username)
    if not user:
        return None
    if not verify_password(password, user.hashed_password):
        return None
    return user


async def get_current_user(
    token: str = Depends(oauth2_scheme),
    db: Session = Depends(get_db)
) -> User:
    """
    Dependency to get current authenticated user from JWT token.

    Raises:
        HTTPException: If token is invalid or user not found
    """
    credentials_exception = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="Could not validate credentials",
        headers={"WWW-Authenticate": "Bearer"},
    )

    username = decode_access_token(token)
    if username is None:
        raise credentials_exception

    user = get_user_by_username(db, username)
    if user is None:
        raise credentials_exception

    return user


async def get_current_active_user(current_user: User = Depends(get_current_user)) -> User:
    """
    Dependency to get current active user.

    Raises:
        HTTPException: If user is inactive
    """
    if not current_user.is_active:
        raise HTTPException(status_code=400, detail="Inactive user")
    return current_user


@router.post("/register", response_model=UserResponse, status_code=status.HTTP_201_CREATED)
async def register_user(user_data: UserCreate, db: Session = Depends(get_db)):
    """
    Register a new user.

    Checks if username or email already exists before creating user.
    """
    logger.info(f"Registration attempt for username: {user_data.username}")

    # Check if username exists
    if get_user_by_username(db, user_data.username):
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="Username already registered"
        )

    # Check if email exists
    existing_email = db.query(User).filter(User.email == user_data.email).first()
    if existing_email:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="Email already registered"
        )

    # Create new user
    hashed_password = get_password_hash(user_data.password)
    db_user = User(
        username=user_data.username,
        email=user_data.email,
        full_name=user_data.full_name,
        hashed_password=hashed_password,
        role=UserRole(user_data.role)
    )

    db.add(db_user)
    db.commit()
    db.refresh(db_user)

    logger.info(f"User registered successfully: {db_user.username}")
    return db_user


@router.post("/login", response_model=Token)
async def login(
    form_data: OAuth2PasswordRequestForm = Depends(),
    db: Session = Depends(get_db)
):
    """
    Login endpoint to get JWT token.

    Expects form data with 'username' and 'password' fields.
    Returns JWT access token if credentials are valid.
    """
    logger.info(f"Login attempt for username: {form_data.username}")

    user = authenticate_user(db, form_data.username, form_data.password)
    if not user:
        logger.warning(f"Failed login attempt for username: {form_data.username}")
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Incorrect username or password",
            headers={"WWW-Authenticate": "Bearer"},
        )

    access_token_expires = timedelta(minutes=settings.access_token_expire_minutes)
    access_token = create_access_token(
        data={"sub": user.username},
        expires_delta=access_token_expires
    )

    logger.info(f"User logged in successfully: {user.username}")
    return {"access_token": access_token, "token_type": "bearer"}


@router.get("/me", response_model=UserResponse)
async def get_current_user_info(current_user: User = Depends(get_current_active_user)):
    """
    Get current authenticated user information.

    This endpoint requires authentication (JWT token in Authorization header).
    """
    return current_user
```

**Authentication Flow Explained:**

1. **User Registration:**
   - User sends username, email, password, etc.
   - Password is hashed with bcrypt
   - User saved to database (password never stored in plain text)

2. **Login:**
   - User sends username + password
   - Server verifies password against hashed version
   - If valid, creates JWT token containing username
   - Returns token to client

3. **Protected Endpoints:**
   - Client sends token in `Authorization: Bearer <token>` header
   - `oauth2_scheme` extracts token from header
   - `get_current_user` validates token and fetches user
   - Endpoint receives authenticated user object

@app.post("/api/v1/predict", response_model=PredictionResponse, tags=["Predictions"])
async def predict_loan_risk(
    application: LoanApplicationRequest,
    db: Session = Depends(get_db),
    current_user = Depends(auth.get_current_active_user)  # PROTECTED ENDPOINT
):
    """
    Predict loan default risk and save to database.

    **Requires authentication.**
    """
    logger.info(f"Prediction requested by {current_user.username} for {application.applicant_name}")

    # Mock prediction logic
    debt_to_income = application.loan_amount / (application.monthly_income * 12)
    base_risk = min(debt_to_income / 10, 0.9)
    risk_score = base_risk + random.uniform(-0.1, 0.1)
    risk_score = max(0.0, min(1.0, risk_score))

    if risk_score < 0.2:
        risk_category = RiskCategory.VERY_LOW
        recommendation = "APPROVE - Excellent candidate"
    elif risk_score < 0.4:
        risk_category = RiskCategory.LOW
        recommendation = "APPROVE - Good candidate"

        risk_category = RiskCategory.MEDIUM
        recommendation = "REVIEW - Manual review recommended"
    elif risk_score < 0.8:
        risk_category = RiskCategory.HIGH
        recommendation = "REJECT - High risk of default"
    else:
        risk_category = RiskCategory.VERY_HIGH
        recommendation = "REJECT - Very high risk"

    db_application = LoanApplication(
        applicant_name=application.applicant_name,
        age=application.age,
        employment_status=EmploymentStatus(application.employment_status),
        monthly_income=application.monthly_income,
        loan_amount=application.loan_amount,
        loan_purpose=application.loan_purpose,
        predicted_risk=risk_category,
        risk_score=round(risk_score, 3),
        recommendation=recommendation
    )

    db.add(db_application)
    db.commit()
    db.refresh(db_application)

    logger.info(f"Application saved with ID: {db_application.id}")

    return PredictionResponse(
        applicant_name=application.applicant_name,
        loan_amount=application.loan_amount,
        predicted_risk=risk_category.value,
        risk_score=round(risk_score, 3),
        recommendation=recommendation,
        timestamp=datetime.utcnow()
    )

## Understanding the Authorization Header

**Format:**
```
Authorization: Bearer <token>
```

**In curl:**
```bash
-H "Authorization: Bearer eyJhbGci..."
```

**Why "Bearer"?**
Bearer authentication means "whoever bears (carries) this token has access" - the token itself is proof of identity.

## Troubleshooting

**Issue:** `"detail": "Not authenticated"`
**Solution:** Make sure you're sending the `Authorization: Bearer <token>` header

**Issue:** Token doesn't work
**Solution:** Check token hasn't expired, verify SECRET_KEY is consistent

**Issue:** Password validation fails
**Solution:** Check password is hashed before storing, use `verify_password()` to check

**Issue:** `401 Unauthorized` on all requests
**Solution:** Verify token format is correct (Bearer + space + token)
