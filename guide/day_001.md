## Step 2: Set Up Python Virtual Environment

**Why a virtual environment?**
A virtual environment isolates your project's dependencies from other Python projects. This prevents version conflicts and keeps your system Python clean.

```bash
# Create virtual environment
python3 -m venv venv

# Activate it (Linux/Mac)
source venv/bin/activate

# Activate it (Windows)
# venv\Scripts\activate

# Verify it's active - you should see (venv) in your prompt
which python  # Should point to venv/bin/python
```

## Step 5: Create Essential Configuration Files

### 5.1 Create `.gitignore`

```bash
cat > .gitignore << 'EOF'
# Python
__pycache__/
*.py[cod]
*$py.class
*.so
.Python
venv/
env/
ENV/

# Environment variables
.env
.env.local

# IDEs
.vscode/
.idea/
*.swp
*.swo

# Data files
data/raw/*
data/processed/*
data/models/*
!data/raw/.gitkeep
!data/processed/.gitkeep
!data/models/.gitkeep

# Logs
logs/*.log
*.log

# OS
.DS_Store
Thumbs.db

# Jupyter
.ipynb_checkpoints/

# MLflow
mlruns/

# Database
*.db
*.sqlite3
EOF
```

**What's .gitignore?**
This file tells Git which files/folders to ignore. We don't want to commit virtual environments, logs, or large data files to version control.

### 5.2 Create `.gitkeep` files

These empty files ensure Git tracks our empty data folders:

```bash
touch data/raw/.gitkeep
touch data/processed/.gitkeep
touch data/models/.gitkeep
touch logs/.gitkeep
```

### 5.3 Create `.env.example`

This will be a template for environment variables (we'll use it tomorrow):

```bash
cat > .env.example << 'EOF'
# API Configuration
API_HOST=0.0.0.0
API_PORT=8000
DEBUG=True

# Database
DATABASE_URL=postgresql://user:password@localhost:5432/credit_risk

# Security
SECRET_KEY=your-secret-key-change-this
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379
EOF
```

**What are environment variables?**
These are configuration values that change between environments (development, production). We keep them in `.env` files to avoid hardcoding secrets in our code.

**Issue:** Permission denied creating folders
