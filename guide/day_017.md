## Understanding API Security

**Why API security matters:**

1. **Rate Limiting:**
   - Prevents DDoS attacks
   - Stops abuse and scraping
   - Ensures fair usage
   - Protects infrastructure costs

2. **Authentication:**
   - JWT: User-based auth (we have this)
   - API Keys: Service-to-service auth
   - Both together: Defense in depth

3. **CORS:**
   - Controls which domains can call API
   - Prevents unauthorized access from browsers

4. **Security Headers:**
   - Prevent XSS, clickjacking, etc.
   - Industry best practices

**Common API attacks:**
- **DDoS:** Overwhelming with requests
- **Brute force:** Trying many passwords
- **SQL Injection:** Malicious database queries (Pydantic prevents this!)
- **XSS:** Cross-site scripting
- **CSRF:** Cross-site request forgery

## Step 2: Create Rate Limiting Module

**File:** `src/utils/rate_limiter.py`

```python
"""
Rate limiting configuration for API endpoints.
"""

from slowapi import Limiter, _rate_limit_exceeded_handler
from slowapi.util import get_remote_address
from slowapi.errors import RateLimitExceeded
from fastapi import Request
from src.utils.logger import logger


def get_identifier(request: Request) -> str:
    """
    Get unique identifier for rate limiting.

    Uses IP address by default, but could use API key or user ID.

    Args:
        request: FastAPI request object

    Returns:
        Unique identifier string
    """
    # Check if user is authenticated
    if hasattr(request.state, "user_id"):
        identifier = f"user:{request.state.user_id}"
    else:
        # Fall back to IP address
        identifier = get_remote_address(request)

    return identifier


# Create limiter instance
limiter = Limiter(
    key_func=get_identifier,
    default_limits=["200/hour"],  # Default: 200 requests per hour
    storage_uri="memory://",  # Use in-memory storage (Redis in production)
    strategy="fixed-window"  # Rate limit strategy
)


def custom_rate_limit_handler(request: Request, exc: RateLimitExceeded):
    """
    Custom error response for rate limit exceeded.

    Args:
        request: FastAPI request
        exc: RateLimitExceeded exception

    Returns:
        JSON error response
    """
    logger.warning(
        f"Rate limit exceeded for {get_identifier(request)} "
        f"on {request.url.path}"
    )

    return {
        "error": "Rate limit exceeded",
        "message": f"Too many requests. Limit: {exc.detail}",
        "retry_after": exc.headers.get("Retry-After", "Unknown")
    }
```

**Rate Limiting Concepts:**

1. **Strategies:**
   - **Fixed Window:** X requests per Y seconds (simple)
   - **Sliding Window:** More accurate, harder to game
   - **Token Bucket:** Allows bursts

2. **Storage:**
   - **Memory:** Fast, but doesn't work with multiple servers
   - **Redis:** Distributed, works across servers
   - **Database:** Persistent, slower

3. **Identifier:**
   - IP address: Simple, but shared IPs problem
   - User ID: Fair, but requires authentication
   - API key: For service-to-service

## Step 3: Create API Key Authentication

**File:** `src/api/api_keys.py`

```python
"""
API key authentication system.
"""

from fastapi import HTTPException, Security, status
from fastapi.security import APIKeyHeader
from typing import Optional
import secrets
import hashlib
from datetime import datetime

from src.utils.logger import logger


# API key header name
API_KEY_NAME = "X-API-Key"
api_key_header = APIKeyHeader(name=API_KEY_NAME, auto_error=False)


# In-memory store (use database in production)
API_KEYS = {
    # Hash of "test_api_key_12345"
    "8c6976e5b5410415bde908bd4dee15dfb167a9c873fc4bb8a81f6f2ab448a918": {
        "name": "Test Service",
        "created_at": "2025-01-20T00:00:00",
        "rate_limit": "1000/hour",
        "active": True
    }
}


def hash_api_key(api_key: str) -> str:
    """
    Hash API key for secure storage.

    Args:
        api_key: Plain API key

    Returns:
        SHA-256 hash
    """
    return hashlib.sha256(api_key.encode()).hexdigest()


def generate_api_key() -> str:
    """
    Generate a new API key.

    Returns:
        32-character random API key
    """
    return secrets.token_urlsafe(32)


async def get_api_key(api_key_header: str = Security(api_key_header)) -> Optional[dict]:
    """
    Validate API key from header.

    Args:
        api_key_header: API key from X-API-Key header

    Returns:
        API key metadata if valid

    Raises:
        HTTPException: If API key is invalid or missing
    """
    if api_key_header is None:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Missing API key",
            headers={"WWW-Authenticate": "ApiKey"}
        )

    # Hash the provided key
    hashed_key = hash_api_key(api_key_header)

    # Look up in store
    key_data = API_KEYS.get(hashed_key)

    if not key_data:
        logger.warning(f"Invalid API key attempted: {api_key_header[:10]}...")
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Invalid API key"
        )

    if not key_data.get("active", True):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="API key is deactivated"
        )

    logger.info(f"API key validated: {key_data['name']}")
    return key_data


def create_api_key(name: str, rate_limit: str = "1000/hour") -> tuple:
    """
    Create a new API key.

    Args:
        name: Name/description of the service
        rate_limit: Rate limit for this key

    Returns:
        (api_key, key_data) tuple
    """
    api_key = generate_api_key()
    hashed = hash_api_key(api_key)

    key_data = {
        "name": name,
        "created_at": datetime.utcnow().isoformat(),
        "rate_limit": rate_limit,
        "active": True
    }

    API_KEYS[hashed] = key_data

    logger.info(f"Created API key for: {name}")

    return api_key, key_data
```

**API Key Concepts:**

1. **Why hash?**
   - Store hash, not plain key
   - If database leaked, keys are safe
   - Like password hashing

2. **Generation:**
   - `secrets.token_urlsafe()`: Cryptographically secure
   - URL-safe characters
   - Unpredictable

3. **Header authentication:**
   - `X-API-Key` header (common convention)
   - Alternative to `Authorization: Bearer`

## Step 4: Add Security Headers Middleware

**File:** `src/api/security_middleware.py`

```python
"""
Security middleware for API.
"""

from fastapi import Request, Response
from fastapi.middleware.cors import CORSMiddleware
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.responses import Response as StarletteResponse
import time

from src.utils.logger import logger


class SecurityHeadersMiddleware(BaseHTTPMiddleware):
    """
    Add security headers to all responses.
    """

    async def dispatch(self, request: Request, call_next):
        """
        Process request and add security headers.

        Args:
            request: Incoming request
            call_next: Next middleware/route handler

        Returns:
            Response with security headers
        """
        response = await call_next(request)

        # Security headers
        response.headers["X-Content-Type-Options"] = "nosniff"
        response.headers["X-Frame-Options"] = "DENY"
        response.headers["X-XSS-Protection"] = "1; mode=block"
        response.headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains"
        response.headers["Referrer-Policy"] = "strict-origin-when-cross-origin"
        response.headers["Permissions-Policy"] = "geolocation=(), microphone=(), camera=()"

        return response


class RequestLoggingMiddleware(BaseHTTPMiddleware):
    """
    Log all API requests for monitoring.
    """

    async def dispatch(self, request: Request, call_next):
        """
        Log request details.

        Args:
            request: Incoming request
            call_next: Next middleware/route handler

        Returns:
            Response
        """
        start_time = time.time()

        # Process request
        response = await call_next(request)

        # Calculate duration
        duration = time.time() - start_time

        # Log request
        logger.info(
            f"{request.method} {request.url.path} "
            f"- Status: {response.status_code} "
            f"- Duration: {duration:.3f}s "
            f"- IP: {request.client.host if request.client else 'Unknown'}"
        )

        return response


class RequestSizeLimitMiddleware(BaseHTTPMiddleware):
    """
    Limit request body size to prevent memory attacks.
    """

    def __init__(self, app, max_size: int = 10 * 1024 * 1024):  # 10 MB default
        super().__init__(app)
        self.max_size = max_size

    async def dispatch(self, request: Request, call_next):
        """
        Check request size.

        Args:
            request: Incoming request
            call_next: Next middleware/route handler

        Returns:
            Response or error
        """
        # Check Content-Length header
        content_length = request.headers.get("content-length")

        if content_length:
            content_length = int(content_length)
            if content_length > self.max_size:
                logger.warning(
                    f"Request too large: {content_length} bytes "
                    f"(max: {self.max_size} bytes)"
                )
                return StarletteResponse(
                    content="Request body too large",
                    status_code=413
                )

        return await call_next(request)
```

**Security Headers Explained:**

1. **X-Content-Type-Options: nosniff**
   - Prevents MIME type sniffing
   - Browser trusts Content-Type header

2. **X-Frame-Options: DENY**
   - Prevents clickjacking
   - Page can't be embedded in iframe

3. **X-XSS-Protection: 1; mode=block**
   - Enables browser XSS filter
   - Blocks page if XSS detected

4. **Strict-Transport-Security (HSTS)**
   - Forces HTTPS
   - Browser remembers for 1 year

5. **Referrer-Policy**
   - Controls Referer header
   - Protects user privacy

6. **Permissions-Policy**
   - Disables browser features
   - Prevents misuse of geolocation, camera, etc.

## Step 7: Create API Key Management Endpoints

**File:** `src/api/admin_routes.py`

```python
"""
Admin endpoints for managing API keys.
"""

from fastapi import APIRouter, HTTPException, Depends
from pydantic import BaseModel

from src.api import auth
from src.api.api_keys import create_api_key, API_KEYS
from src.models.database_models import UserRole
from src.utils.logger import logger


router = APIRouter(prefix="/api/v1/admin", tags=["Admin"])


class APIKeyCreate(BaseModel):
    """Request schema for creating API key."""
    name: str
    rate_limit: str = "1000/hour"


class APIKeyResponse(BaseModel):
    """Response schema for API key."""
    api_key: str
    name: str
    rate_limit: str
    created_at: str


@router.post("/api-keys", response_model=APIKeyResponse)
async def create_new_api_key(
    key_request: APIKeyCreate,
    current_user = Depends(auth.get_current_active_user)
):
    """
    Create a new API key.

    **Requires:** Admin role
    """
    # Check if user is admin
    if current_user.role != UserRole.ADMIN:
        raise HTTPException(
            status_code=403,
            detail="Only admins can create API keys"
        )

    api_key, key_data = create_api_key(
        name=key_request.name,
        rate_limit=key_request.rate_limit
    )

    logger.info(f"Admin {current_user.username} created API key for: {key_request.name}")

    return {
        "api_key": api_key,
        "name": key_data["name"],
        "rate_limit": key_data["rate_limit"],
        "created_at": key_data["created_at"]
    }


@router.get("/api-keys")
async def list_api_keys(current_user = Depends(auth.get_current_active_user)):
    """
    List all API keys (without showing actual keys).

    **Requires:** Admin role
    """
    if current_user.role != UserRole.ADMIN:
        raise HTTPException(
            status_code=403,
            detail="Only admins can view API keys"
        )

    keys_list = []
    for hashed_key, data in API_KEYS.items():
        keys_list.append({
            "name": data["name"],
            "created_at": data["created_at"],
            "rate_limit": data["rate_limit"],
            "active": data["active"],
            "key_hash": hashed_key[:16] + "..."  # Show partial hash
        })

    return {
        "total_keys": len(keys_list),
        "keys": keys_list
    }
```

## Rate Limiting Best Practices

**Recommended limits:**

| Endpoint Type | Limit | Reasoning |
|--------------|-------|-----------|
| Health check | 30/minute | High frequency ok |
| Login | 5/minute | Prevent brute force |
| Predictions (single) | 60/minute | Normal usage |
| Predictions (batch) | 10/minute | Resource intensive |
| API key (batch) | 100/hour | Trusted services |

**Storage options:**

| Storage | Pros | Cons | Use Case |
|---------|------|------|----------|
| Memory | Fast, simple | Single server only | Development |
| Redis | Distributed, fast | Extra dependency | Production |
| Database | Persistent | Slower | Long-term tracking |
