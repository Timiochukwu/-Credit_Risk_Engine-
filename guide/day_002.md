## Step 3: Create Configuration Module

**File:** `src/utils/config.py`

```python
"""
Configuration management using Pydantic Settings.
Loads from environment variables and .env file.
"""

from pydantic_settings import BaseSettings
from pydantic import Field


class Settings(BaseSettings):
    """Application settings loaded from environment variables."""

    # API Configuration
    api_host: str = Field(default="0.0.0.0", alias="API_HOST")
    api_port: int = Field(default=8000, alias="API_PORT")
    debug: bool = Field(default=False, alias="DEBUG")
    project_name: str = Field(default="Credit Risk API", alias="PROJECT_NAME")
    version: str = Field(default="0.1.0", alias="VERSION")

    class Config:
        env_file = ".env"
        case_sensitive = False


# Global settings instance
settings = Settings()
```

**Concepts Explained:**

1. **BaseSettings:** Pydantic class that auto-loads from environment variables
2. **Field():** Defines default values and aliases
3. **alias:** Maps environment variable names (API_HOST) to Python attributes (api_host)
4. **Config.env_file:** Automatically loads from .env file

## Step 4: Create Logger Utility

**File:** `src/utils/logger.py`

```python
"""
Logging configuration for the application.
"""

import logging
import sys
from pathlib import Path


def setup_logger(name: str = "credit_risk_api") -> logging.Logger:
    """
    Set up a logger with console and file handlers.

    Args:
        name: Logger name

    Returns:
        Configured logger instance
    """
    logger = logging.getLogger(name)
    logger.setLevel(logging.DEBUG)

    # Avoid adding handlers multiple times
    if logger.handlers:
        return logger

    # Format for log messages
    formatter = logging.Formatter(
        '%(asctime)s - %(name)s - %(levelname)s - %(message)s',
        datefmt='%Y-%m-%d %H:%M:%S'
    )

    # Console handler (stdout)
    console_handler = logging.StreamHandler(sys.stdout)
    console_handler.setLevel(logging.INFO)
    console_handler.setFormatter(formatter)
    logger.addHandler(console_handler)

    # File handler
    log_dir = Path("logs")
    log_dir.mkdir(exist_ok=True)
    file_handler = logging.FileHandler(log_dir / "api.log")
    file_handler.setLevel(logging.DEBUG)
    file_handler.setFormatter(formatter)
    logger.addHandler(file_handler)

    return logger


# Global logger instance
logger = setup_logger()
```

**Why logging?**
- Track what's happening in your API
- Debug issues in production
- Monitor performance and errors

## Step 5: Create Pydantic Schemas

**File:** `src/api/schemas.py`

```python
"""
Pydantic schemas for request/response validation.
"""

from pydantic import BaseModel, Field
from typing import Literal
from datetime import datetime


class HealthResponse(BaseModel):
    """Response schema for health check endpoint."""
    status: str
    timestamp: datetime
    version: str


class LoanApplicationRequest(BaseModel):
    """Schema for loan application prediction request (mock for now)."""

    applicant_name: str = Field(..., min_length=2, max_length=100)
    loan_amount: float = Field(..., gt=0, le=100_000_000)
    monthly_income: float = Field(..., gt=0)
    employment_status: Literal["EMPLOYED", "SELF_EMPLOYED", "UNEMPLOYED"]
    age: int = Field(..., ge=18, le=100)

    class Config:
        json_schema_extra = {
            "example": {
                "applicant_name": "Adebayo Johnson",
                "loan_amount": 5000000,
                "monthly_income": 500000,
                "employment_status": "EMPLOYED",
                "age": 35
            }
        }


class PredictionResponse(BaseModel):
    """Response schema for prediction endpoint."""

    applicant_name: str
    loan_amount: float
    predicted_risk: Literal["VERY_LOW", "LOW", "MEDIUM", "HIGH", "VERY_HIGH"]
    risk_score: float = Field(..., ge=0.0, le=1.0)
    recommendation: str
    timestamp: datetime
```

**Pydantic Schemas Explained:**

- **BaseModel:** Base class for all schemas
- **Field(...):** Required field (the `...` means no default)
- **Field(gt=0):** Greater than 0 validation
- **Field(ge=18, le=100):** Between 18 and 100
- **Literal:** Only accepts specific string values
- **Config.json_schema_extra:** Example data for API docs

## Step 6: Create Main FastAPI Application

**File:** `src/api/main.py`

```python
"""
Main FastAPI application for Nigerian Credit Risk Engine.
"""

from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from datetime import datetime
import random

from src.utils.config import settings
from src.utils.logger import logger
from src.api.schemas import (
    HealthResponse,
    LoanApplicationRequest,
    PredictionResponse
)


# Initialize FastAPI app
app = FastAPI(
    title=settings.project_name,
    version=settings.version,
    description="Machine Learning API for Credit Risk Assessment",
    docs_url="/docs",
    redoc_url="/redoc"
)

# Add CORS middleware (allows frontend to call this API)
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # In production, specify exact origins
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.on_event("startup")
async def startup_event():
    """Run on application startup."""
    logger.info(f"Starting {settings.project_name} v{settings.version}")
    logger.info(f"Debug mode: {settings.debug}")


@app.on_event("shutdown")
async def shutdown_event():
    """Run on application shutdown."""
    logger.info("Shutting down API")


@app.get("/", tags=["Root"])
async def root():
    """Root endpoint with API information."""
    return {
        "name": settings.project_name,
        "version": settings.version,
        "status": "running",
        "docs": "/docs",
        "health": "/health"
    }


@app.get("/health", response_model=HealthResponse, tags=["Health"])
async def health_check():
    """
    Health check endpoint.
    Returns API status and version.
    """
    logger.debug("Health check requested")
    return HealthResponse(
        status="healthy",
        timestamp=datetime.utcnow(),
        version=settings.version
    )


@app.post("/api/v1/predict", response_model=PredictionResponse, tags=["Predictions"])
async def predict_loan_risk(application: LoanApplicationRequest):
    """
    Predict loan default risk (MOCK VERSION - no ML yet).

    This is a placeholder that returns random predictions.
    We'll replace this with real ML models in later days.
    """
    logger.info(f"Prediction requested for {application.applicant_name}")

    # Mock logic: Calculate a fake risk score
    # Higher loan_amount / monthly_income ratio = higher risk
    debt_to_income = application.loan_amount / (application.monthly_income * 12)

    # Add some randomness
    base_risk = min(debt_to_income / 10, 0.9)
    risk_score = base_risk + random.uniform(-0.1, 0.1)
    risk_score = max(0.0, min(1.0, risk_score))  # Clamp between 0 and 1

    # Categorize risk
    if risk_score < 0.2:
        risk_category = "VERY_LOW"
        recommendation = "APPROVE - Excellent candidate"
    elif risk_score < 0.4:
        risk_category = "LOW"
        recommendation = "APPROVE - Good candidate"
    elif risk_score < 0.6:
        risk_category = "MEDIUM"
        recommendation = "REVIEW - Manual review recommended"
    elif risk_score < 0.8:
        risk_category = "HIGH"
        recommendation = "REJECT - High risk of default"
    else:
        risk_category = "VERY_HIGH"
        recommendation = "REJECT - Very high risk"

    logger.info(f"Predicted risk: {risk_category} (score: {risk_score:.3f})")

    return PredictionResponse(
        applicant_name=application.applicant_name,
        loan_amount=application.loan_amount,
        predicted_risk=risk_category,
        risk_score=round(risk_score, 3),
        recommendation=recommendation,
        timestamp=datetime.utcnow()
    )
```

**FastAPI Concepts Explained:**

1. **`app = FastAPI(...)`:** Creates the application instance
2. **`@app.get("/path")`:** Decorator that creates a GET endpoint
3. **`async def`:** Asynchronous function (allows handling multiple requests efficiently)
4. **`response_model=`:** Pydantic validates the response matches this schema
5. **`tags=`:** Groups endpoints in the API documentation
6. **Middleware:** Code that runs before/after each request (CORS allows cross-origin requests)

## Step 7: Run the API

Start the server:

```bash
uvicorn src.api.main:app --host 0.0.0.0 --port 8000 --reload
```

**Command breakdown:**
- `src.api.main:app` → Python module path to your FastAPI `app` instance
- `--host 0.0.0.0` → Listen on all network interfaces
- `--port 8000` → Listen on port 8000
- `--reload` → Auto-restart when code changes (dev only!)

You should see:

## Understanding curl

**Basic syntax:**
```bash
curl [options] URL
```

**Common options:**
- `-X POST` → HTTP method (GET is default)
- `-H "Header: value"` → Add HTTP header
- `-d '{"key": "value"}'` → Send JSON data
- `-i` → Include response headers
- `-v` → Verbose output (shows full request/response)

**Formatting JSON output:**
```bash
curl http://localhost:8000/health | jq
```
(Install jq: `sudo apt-get install jq` or `brew install jq`)

## Troubleshooting

**Issue:** `ModuleNotFoundError: No module named 'src'`
**Solution:** Run uvicorn from the project root directory

**Issue:** Port 8000 already in use
**Solution:** `lsof -ti:8000 | xargs kill` or use a different port

**Issue:** CORS errors in browser
**Solution:** Already configured with `allow_origins=["*"]` in middleware

**Issue:** Changes not reflected
**Solution:** Check that `--reload` flag is set when running uvicorn
