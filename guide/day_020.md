# Day 020: Production Deployment

**Estimated Time:** 2 hours

## Goal
Deploy the Nigerian Credit Risk Engine to a production environment with proper security, scalability, monitoring, and reliability. Set up Nginx reverse proxy, SSL certificates, process management, automated backups, and implement a comprehensive production deployment checklist.

---

## Why Production Deployment is Different

Development vs Production:

| Aspect | Development | Production |
|--------|------------|-----------|
| **Security** | Relaxed | Strict (HTTPS, secrets, firewalls) |
| **Performance** | Single worker | Multiple workers, load balancing |
| **Reliability** | Restarts acceptable | Auto-restart, health checks |
| **Monitoring** | Basic logs | Comprehensive monitoring |
| **Data** | Test data | Real customer data (PII) |
| **Availability** | 9-5 availability | 99.9% uptime SLA |

**Production Requirements:**
1. **HTTPS/SSL** - Encrypt all traffic
2. **Reverse Proxy** - Nginx for load balancing and security
3. **Process Management** - Auto-restart on crashes
4. **Secrets Management** - No hardcoded credentials
5. **Monitoring** - Track health, errors, performance
6. **Backups** - Regular database and model backups
7. **Log Management** - Rotation and retention
8. **Scalability** - Handle traffic spikes

## File 2: Production Gunicorn Configuration

**File:** `gunicorn_config.py`

```python
"""
Gunicorn configuration for production deployment
"""
import multiprocessing
import os

# Server socket
bind = f"{os.getenv('HOST', '0.0.0.0')}:{os.getenv('PORT', '8000')}"
backlog = 2048

# Worker processes
workers = int(os.getenv('WORKERS', multiprocessing.cpu_count() * 2 + 1))
worker_class = "uvicorn.workers.UvicornWorker"
worker_connections = 1000
max_requests = 1000  # Restart worker after N requests (prevents memory leaks)
max_requests_jitter = 50
timeout = 120  # Worker timeout (seconds)
keepalive = 5

# Logging
accesslog = "logs/access.log"
errorlog = "logs/error.log"
loglevel = os.getenv('LOG_LEVEL', 'info')
access_log_format = '%(h)s %(l)s %(u)s %(t)s "%(r)s" %(s)s %(b)s "%(f)s" "%(a)s" %(D)s'

# Process naming
proc_name = "credit_risk_api"

# Server mechanics
daemon = False  # Run in foreground (systemd manages daemonization)
pidfile = "/tmp/credit_risk_api.pid"
umask = 0
user = None
group = None
tmp_upload_dir = None

# Security
limit_request_line = 4094
limit_request_fields = 100
limit_request_field_size = 8190

# SSL (if terminating SSL at Gunicorn instead of Nginx)
# keyfile = "/path/to/ssl/key.pem"
# certfile = "/path/to/ssl/cert.pem"
```

**Key Concepts:**

1. **Workers**: `(2 x CPU cores) + 1` is industry standard
   - 4-core server = 9 workers
   - Each worker handles requests independently

2. **Max Requests**: Restart workers after N requests to prevent memory leaks

3. **Timeout**: Kill workers that take too long (prevents hangs)

4. **Worker Class**: `UvicornWorker` for ASGI support (FastAPI requires this)

```nginx
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # Timeouts
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;

        # Buffering
        proxy_buffering on;
        proxy_buffer_size 4k;
        proxy_buffers 8 4k;
        proxy_busy_buffers_size 8k;
    }

    # Health check endpoint
    location /health {
        proxy_pass http://credit_risk_backend;
        access_log off;
    }

    # Static files (if any)
    location /static {
        alias /opt/credit_risk_engine/static;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # Deny access to hidden files
    location ~ /\. {
        deny all;
        access_log off;
        log_not_found off;
    }
}
```

**Key Features:**

1. **HTTP → HTTPS Redirect**: All traffic forced to HTTPS
2. **SSL/TLS**: Modern, secure configuration
3. **Rate Limiting**: 10 requests/second per IP
4. **Security Headers**: HSTS, X-Frame-Options, etc.
5. **Gzip Compression**: Reduces bandwidth
6. **Load Balancing**: Ready for multiple backend servers

## File 5: Automated Backup Script

**File:** `scripts/backup.sh`

```bash
#!/bin/bash
#
# Automated backup script for Credit Risk Engine
# Run daily via cron: 0 3 * * * /opt/credit_risk_engine/scripts/backup.sh
#

set -e  # Exit on error

# Configuration
BACKUP_DIR="/var/backups/credit_risk"
RETENTION_DAYS=30
DATE=$(date +%Y%m%d_%H%M%S)

# Database credentials (from environment or .env)
source /opt/credit_risk_engine/.env.production
DB_NAME="credit_risk_prod"
DB_USER="prod_user"

# Create backup directory
mkdir -p "$BACKUP_DIR"

echo "Starting backup at $(date)"

# 1. Database backup
echo "Backing up PostgreSQL database..."
pg_dump -U "$DB_USER" "$DB_NAME" | gzip > "$BACKUP_DIR/db_backup_$DATE.sql.gz"

# 2. Model files backup
echo "Backing up model files..."
tar -czf "$BACKUP_DIR/models_backup_$DATE.tar.gz" -C /opt/credit_risk_engine models/

# 3. Configuration backup
echo "Backing up configuration..."
tar -czf "$BACKUP_DIR/config_backup_$DATE.tar.gz" \
    -C /opt/credit_risk_engine \
    --exclude='venv' \
    --exclude='__pycache__' \
    --exclude='*.pyc' \
    .

# 4. Remove old backups
echo "Cleaning up old backups (older than $RETENTION_DAYS days)..."
find "$BACKUP_DIR" -name "*.gz" -type f -mtime +$RETENTION_DAYS -delete

# 5. Backup to cloud (optional - AWS S3 example)
# Uncomment if using AWS S3
# echo "Uploading to S3..."
# aws s3 sync "$BACKUP_DIR" s3://your-bucket/credit-risk-backups/ --delete

# Calculate backup sizes
DB_SIZE=$(du -h "$BACKUP_DIR/db_backup_$DATE.sql.gz" | cut -f1)
MODEL_SIZE=$(du -h "$BACKUP_DIR/models_backup_$DATE.tar.gz" | cut -f1)

echo "Backup completed at $(date)"
echo "Database backup: $DB_SIZE"
echo "Models backup: $MODEL_SIZE"
echo "Backup location: $BACKUP_DIR"

# Send notification (optional)
# echo "Backup completed successfully" | mail -s "Credit Risk Backup - $DATE" admin@creditrisk.ng
```

## File 6: Health Check Endpoint

**File:** Update `src/api/main.py`

Add comprehensive health check:

```python
from datetime import datetime
from sqlalchemy import text

@app.get("/health", tags=["health"])
async def health_check(db: Session = Depends(get_db)):
    """
    Comprehensive health check endpoint

    Checks:
    - API is running
    - Database connectivity
    - Model availability
    - Disk space
    """
    health_status = {
        "status": "healthy",
        "timestamp": datetime.utcnow().isoformat(),
        "checks": {}
    }

    # Check database
    try:
        db.execute(text("SELECT 1"))
        health_status["checks"]["database"] = "healthy"
    except Exception as e:
        health_status["checks"]["database"] = f"unhealthy: {str(e)}"
        health_status["status"] = "unhealthy"

    # Check model availability
    try:
        from src.retraining.model_versioner import ModelVersionManager
        version_manager = ModelVersionManager()
        active_version = version_manager.get_active_version()

        if active_version:
            health_status["checks"]["model"] = "healthy"
            health_status["model_version"] = active_version["version_id"]
        else:
            health_status["checks"]["model"] = "no active model"
            health_status["status"] = "degraded"
    except Exception as e:
        health_status["checks"]["model"] = f"unhealthy: {str(e)}"
        health_status["status"] = "unhealthy"

    # Check disk space
    try:
        import shutil
        total, used, free = shutil.disk_usage("/")
        free_percent = (free / total) * 100

        if free_percent > 20:
            health_status["checks"]["disk"] = "healthy"
        elif free_percent > 10:
            health_status["checks"]["disk"] = "degraded"
            health_status["status"] = "degraded"
        else:
            health_status["checks"]["disk"] = "critical"
            health_status["status"] = "unhealthy"

        health_status["disk_free_percent"] = round(free_percent, 2)
    except Exception as e:
        health_status["checks"]["disk"] = f"unhealthy: {str(e)}"

    return health_status
```

```
    daily
    rotate 14
    compress
    delaycompress
    notifempty
    missingok
    create 0644 www-data www-data
    sharedscripts
    postrotate
        systemctl reload credit_risk_api > /dev/null 2>&1 || true
    endscript
}

/var/log/nginx/credit_risk_*.log {
    daily
    rotate 30
    compress
    delaycompress
    notifempty
    missingok
    create 0640 www-data adm
    sharedscripts
    postrotate
        if [ -f /var/run/nginx.pid ]; then
            kill -USR1 `cat /var/run/nginx.pid`
        fi
    endscript
}
```

**What This Does:**
- Rotates logs daily
- Keeps 14 days of application logs, 30 days of Nginx logs
- Compresses old logs (saves disk space)
- Reloads services after rotation

### Deployment Steps

**1. Install Application**

```bash
# Create application directory
sudo mkdir -p /opt/credit_risk_engine
sudo chown www-data:www-data /opt/credit_risk_engine

# Clone repository
cd /opt/credit_risk_engine
sudo -u www-data git clone https://github.com/yourusername/credit-risk-engine.git .

# Create virtual environment
sudo -u www-data python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
pip install gunicorn
```

```bash
# Create production database
sudo -u postgres psql
CREATE DATABASE credit_risk_prod;
CREATE USER prod_user WITH ENCRYPTED PASSWORD 'STRONG_PASSWORD';
GRANT ALL PRIVILEGES ON DATABASE credit_risk_prod TO prod_user;
\q

# Run migrations
cd /opt/credit_risk_engine
source venv/bin/activate
alembic upgrade head
```

```bash
# Copy environment file
cp .env.production /opt/credit_risk_engine/.env.production
```

```bash
# Copy service file
```
