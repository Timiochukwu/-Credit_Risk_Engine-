## What You'll Build Today

Today you'll implement a comprehensive disaster recovery (DR) and backup strategy for your Credit Risk Engine. You'll set up automated database backups, model artifact backups, point-in-time recovery, Kubernetes cluster backups, and create disaster recovery runbooks.

## Why Disaster Recovery?

**Problem**: Without DR, you risk:
- **Data loss**: Database corruption, accidental deletion
- **Extended downtime**: No recovery plan = hours/days offline
- **Model loss**: Cannot revert to previous working model
- **Compliance violations**: Regulations require backup/recovery
- **Business impact**: Revenue loss, reputation damage
- **Career risk**: "We lost everything" is not acceptable

**Solution**: Comprehensive DR provides:
- **Automated backups**: Database, models, configurations
- **Point-in-time recovery**: Restore to any moment
- **Geographic redundancy**: Survive datacenter failures
- **Tested procedures**: Runbooks and regular drills
- **RTO/RPO guarantees**: Recovery Time/Point Objectives

**Benefits**:
- **Data protection**: Never lose critical data
- **Business continuity**: Minimize downtime
- **Compliance**: Meet regulatory requirements
- **Peace of mind**: Sleep well at night
- **Customer trust**: Professional operations

## Part 1: Database Backup Strategy

### Step 1: PostgreSQL Full Backups

**`scripts/backup/pg_backup.sh`**:

```bash
#!/bin/bash
#
# PostgreSQL backup script with compression and retention
#

set -e

# Configuration
DB_NAME="${DB_NAME:-credit_risk_db}"
DB_USER="${DB_USER:-postgres}"
DB_HOST="${DB_HOST:-localhost}"
DB_PORT="${DB_PORT:-5432}"
BACKUP_DIR="${BACKUP_DIR:-/backups/postgres}"
RETENTION_DAYS="${RETENTION_DAYS:-30}"
S3_BUCKET="${S3_BUCKET:-}"  # Optional: upload to S3

# Create backup directory
mkdir -p "$BACKUP_DIR"

# Backup filename with timestamp
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/${DB_NAME}_${TIMESTAMP}.sql.gz"

echo "Starting backup of database: $DB_NAME"
echo "Backup file: $BACKUP_FILE"

# Perform backup with compression
PGPASSWORD="$DB_PASSWORD" pg_dump \
  -h "$DB_HOST" \
  -p "$DB_PORT" \
  -U "$DB_USER" \
  -d "$DB_NAME" \
  --format=custom \
  --compress=9 \
  --file="$BACKUP_FILE.dump"

# Also create SQL backup for easy inspection
PGPASSWORD="$DB_PASSWORD" pg_dump \
  -h "$DB_HOST" \
  -p "$DB_PORT" \
  -U "$DB_USER" \
  -d "$DB_NAME" \
  --format=plain \
  | gzip > "$BACKUP_FILE"

# Calculate checksum
sha256sum "$BACKUP_FILE" > "$BACKUP_FILE.sha256"

echo "Backup completed: $BACKUP_FILE"

# Upload to S3 if configured
if [ -n "$S3_BUCKET" ]; then
  echo "Uploading to S3: s3://$S3_BUCKET/postgres/"
  aws s3 cp "$BACKUP_FILE" "s3://$S3_BUCKET/postgres/"
  aws s3 cp "$BACKUP_FILE.dump" "s3://$S3_BUCKET/postgres/"
  aws s3 cp "$BACKUP_FILE.sha256" "s3://$S3_BUCKET/postgres/"
fi

# Cleanup old backups (keep RETENTION_DAYS)
echo "Cleaning up backups older than $RETENTION_DAYS days"
find "$BACKUP_DIR" -name "${DB_NAME}_*.sql.gz" -mtime +$RETENTION_DAYS -delete
find "$BACKUP_DIR" -name "${DB_NAME}_*.dump" -mtime +$RETENTION_DAYS -delete
find "$BACKUP_DIR" -name "${DB_NAME}_*.sha256" -mtime +$RETENTION_DAYS -delete

echo "Backup process completed successfully"

# List recent backups
echo "Recent backups:"
ls -lh "$BACKUP_DIR" | tail -n 5
```

Make executable:

```bash
chmod +x scripts/backup/pg_backup.sh
```

### Step 2: PostgreSQL WAL Archiving (Point-in-Time Recovery)

**Enable WAL archiving** in PostgreSQL for continuous backup:

**`postgresql.conf`** (on database server):

```conf
# Enable WAL archiving
wal_level = replica
archive_mode = on
archive_command = 'test ! -f /backups/postgres/wal_archive/%f && cp %p /backups/postgres/wal_archive/%f'
archive_timeout = 300  # Archive every 5 minutes
max_wal_senders = 5
wal_keep_size = 1GB
```

**Create WAL archive directory**:

```bash
mkdir -p /backups/postgres/wal_archive
chown postgres:postgres /backups/postgres/wal_archive
```

**Restart PostgreSQL**:

```bash
sudo systemctl restart postgresql
```

### Step 4: Database Restore Procedure

**`scripts/backup/pg_restore.sh`**:

```bash
#!/bin/bash
#
# PostgreSQL restore script
#

set -e

BACKUP_FILE="$1"
DB_NAME="${DB_NAME:-credit_risk_db}"
DB_USER="${DB_USER:-postgres}"
DB_HOST="${DB_HOST:-localhost}"
DB_PORT="${DB_PORT:-5432}"

if [ -z "$BACKUP_FILE" ]; then
  echo "Usage: $0 <backup_file>"
  echo "Example: $0 /backups/postgres/credit_risk_db_20240115_020000.sql.gz"
  exit 1
fi

if [ ! -f "$BACKUP_FILE" ]; then
  echo "Backup file not found: $BACKUP_FILE"
  exit 1
fi

echo "WARNING: This will DROP and RECREATE database: $DB_NAME"
read -p "Are you sure? (yes/no): " confirm

if [ "$confirm" != "yes" ]; then
  echo "Restore cancelled"
  exit 0
fi

# Drop existing database (WARNING!)
echo "Dropping existing database..."
PGPASSWORD="$DB_PASSWORD" psql \
  -h "$DB_HOST" \
  -p "$DB_PORT" \
  -U "$DB_USER" \
  -d postgres \
  -c "DROP DATABASE IF EXISTS $DB_NAME;"

# Create new database
echo "Creating new database..."
PGPASSWORD="$DB_PASSWORD" psql \
  -h "$DB_HOST" \
  -p "$DB_PORT" \
  -U "$DB_USER" \
  -d postgres \
  -c "CREATE DATABASE $DB_NAME;"

# Restore backup
echo "Restoring backup..."
if [[ "$BACKUP_FILE" == *.dump ]]; then
  # Custom format
  PGPASSWORD="$DB_PASSWORD" pg_restore \
    -h "$DB_HOST" \
    -p "$DB_PORT" \
    -U "$DB_USER" \
    -d "$DB_NAME" \
    --jobs=4 \
    --no-owner \
    --no-acl \
    "$BACKUP_FILE"
else
  # SQL format
  gunzip < "$BACKUP_FILE" | PGPASSWORD="$DB_PASSWORD" psql \
    -h "$DB_HOST" \
    -p "$DB_PORT" \
    -U "$DB_USER" \
    -d "$DB_NAME"
fi

echo "Restore completed successfully"
```

## Part 2: Model Artifact Backups

### Step 1: MLflow Model Backup

**`scripts/backup/mlflow_backup.sh`**:

```bash
#!/bin/bash
#
# MLflow artifact store backup
#

set -e

MLFLOW_TRACKING_URI="${MLFLOW_TRACKING_URI:-http://localhost:5000}"
BACKUP_DIR="${BACKUP_DIR:-/backups/mlflow}"
S3_BUCKET="${S3_BUCKET:-}"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)

mkdir -p "$BACKUP_DIR"

echo "Backing up MLflow artifacts..."

# Backup MLflow backend database (SQLite or PostgreSQL)
if [ -f "/mlflow/mlruns.db" ]; then
  # SQLite backend
  cp /mlflow/mlruns.db "$BACKUP_DIR/mlruns_${TIMESTAMP}.db"
  gzip "$BACKUP_DIR/mlruns_${TIMESTAMP}.db"
else
  # PostgreSQL backend
  PGPASSWORD="$MLFLOW_DB_PASSWORD" pg_dump \
    -h "$MLFLOW_DB_HOST" \
    -U "$MLFLOW_DB_USER" \
    -d "$MLFLOW_DB_NAME" \
    | gzip > "$BACKUP_DIR/mlflow_db_${TIMESTAMP}.sql.gz"
fi

# Backup artifact store (local filesystem)
if [ -d "/mlflow/artifacts" ]; then
  tar -czf "$BACKUP_DIR/artifacts_${TIMESTAMP}.tar.gz" \
    -C /mlflow/artifacts .
fi

# Upload to S3
if [ -n "$S3_BUCKET" ]; then
  aws s3 sync "$BACKUP_DIR" "s3://$S3_BUCKET/mlflow/"
fi

echo "MLflow backup completed"
```

### Step 2: Model Registry Snapshot

**`scripts/backup/model_registry_snapshot.py`**:

```python
#!/usr/bin/env python3
"""
Create snapshot of model registry metadata.
"""
import json
from datetime import datetime
from mlflow.tracking import MlflowClient


def create_registry_snapshot(output_file: str):
    """Create JSON snapshot of all registered models."""
    client = MlflowClient()

    snapshot = {
        'timestamp': datetime.now().isoformat(),
        'models': []
    }

    # Get all registered models
    for model in client.search_registered_models():
        model_info = {
            'name': model.name,
            'description': model.description,
            'tags': model.tags,
            'versions': []
        }

        # Get all versions
        for version in client.search_model_versions(f"name='{model.name}'"):
            version_info = {
                'version': version.version,
                'stage': version.current_stage,
                'run_id': version.run_id,
                'creation_timestamp': version.creation_timestamp,
                'description': version.description,
                'tags': version.tags,
                'source': version.source
            }
            model_info['versions'].append(version_info)

        snapshot['models'].append(model_info)

    # Save snapshot
    with open(output_file, 'w') as f:
        json.dump(snapshot, f, indent=2)

    print(f"Registry snapshot saved to: {output_file}")
    print(f"Total models: {len(snapshot['models'])}")


if __name__ == '__main__':
    import sys
    output = sys.argv[1] if len(sys.argv) > 1 else 'model_registry_snapshot.json'
    create_registry_snapshot(output)
```

## Best Practices

### 1. Follow 3-2-1 Backup Rule

- **3** copies of data
- **2** different media types
- **1** copy offsite

```bash
# Local backup
cp backup.sql.gz /backups/local/

# Different media (tape/disk)
cp backup.sql.gz /mnt/nas/

# Offsite (S3/GCS)
aws s3 cp backup.sql.gz s3://bucket/offsite/
```

### 2. Encrypt Backups

```bash
# Encrypt before upload
gpg --encrypt --recipient admin@example.com backup.sql.gz
aws s3 cp backup.sql.gz.gpg s3://bucket/encrypted/

# Decrypt for restore
aws s3 cp s3://bucket/encrypted/backup.sql.gz.gpg .
gpg --decrypt backup.sql.gz.gpg > backup.sql.gz
```

### 3. Monitor Backup Success

```python
# Send alert if backup fails
if backup_exit_code != 0:
    send_alert("Database backup failed!")
```
