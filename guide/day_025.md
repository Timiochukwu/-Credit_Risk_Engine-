## Why Log Aggregation?

**Problems with File-Based Logs:**
- Logs scattered across multiple servers
- No central search capability
- Hard to correlate events across services
- Manual SSH to servers for debugging
- Difficult to detect patterns
- No retention policy management

**Log Aggregation Solution:**
- **Centralized**: All logs in one place
- **Searchable**: Full-text search across all services
- **Structured**: JSON logs are queryable
- **Correlated**: Link logs with traces and metrics
- **Alertable**: Detect error patterns automatically
- **Retained**: Automatic archival and cleanup

**Real-World Use Cases:**
- Find all requests from user_id=123 across all services
- Detect authentication failures spike
- Trace error through database → API → client
- Alert when error rate exceeds threshold
- Investigate incidents with full request context

## Key Concepts

### Structured Logging

**Unstructured (Bad):**
```
2024-01-15 14:30:22 - User john logged in from 192.168.1.1
```

**Structured (Good):**
```json
{
  "timestamp": "2024-01-15T14:30:22Z",
  "level": "INFO",
  "message": "User logged in",
  "user_id": "john",
  "ip_address": "192.168.1.1",
  "trace_id": "abc123",
  "span_id": "def456"
}
```

**Benefits:**
- Queryable fields (`user_id="john"`)
- Machine-parseable
- Easy filtering and aggregation
- Trace correlation built-in

### Log Levels

- **DEBUG**: Detailed diagnostic info
- **INFO**: General informational messages
- **WARNING**: Potential issues, degraded functionality
- **ERROR**: Errors that need attention
- **CRITICAL**: Severe errors, system failure

### Grafana Loki

**Why Loki?**
- From Grafana Labs (integrates perfectly with Grafana)
- Cost-effective (indexes only metadata, not full logs)
- Easy to operate (no Elasticsearch complexity)
- Native support for log streaming
- Works with existing logging infrastructure

**Architecture:**
- **Promtail**: Agent that ships logs to Loki
- **Loki**: Log aggregation server
- **Grafana**: Query and visualization

## File 1: Structured JSON Logger

**File:** Update `src/utils/logger.py`

Replace existing logger with structured version:

```python
"""
Structured JSON Logger
Provides JSON-formatted logging with trace correlation
"""
import logging
import sys
from pythonjsonlogger import jsonlogger
from opentelemetry import trace
from datetime import datetime
import os


class CustomJsonFormatter(jsonlogger.JsonFormatter):
    """Custom JSON formatter with trace context"""

    def add_fields(self, log_record, record, message_dict):
        """Add custom fields to log record"""
        super(CustomJsonFormatter, self).add_fields(log_record, record, message_dict)

        # Add timestamp
        if not log_record.get('timestamp'):
            log_record['timestamp'] = datetime.utcnow().isoformat() + 'Z'

        # Add log level
        if log_record.get('level'):
            log_record['level'] = log_record['level'].upper()
        else:
            log_record['level'] = record.levelname

        # Add trace context (if available)
        span = trace.get_current_span()
        if span.get_span_context().is_valid:
            span_context = span.get_span_context()
            log_record['trace_id'] = format(span_context.trace_id, '032x')
            log_record['span_id'] = format(span_context.span_id, '016x')

        # Add service info
        log_record['service'] = 'credit-risk-api'
        log_record['environment'] = os.getenv('APP_ENV', 'development')


def get_logger(name: str, level: str = None) -> logging.Logger:
    """
    Get a structured JSON logger

    Args:
        name: Logger name (usually __name__)
        level: Log level (DEBUG, INFO, WARNING, ERROR, CRITICAL)

    Returns:
        Configured logger instance
    """
    # Get or create logger
    logger = logging.getLogger(name)

    # Set level
    log_level = level or os.getenv('LOG_LEVEL', 'INFO')
    logger.setLevel(getattr(logging, log_level.upper()))

    # Avoid duplicate handlers
    if logger.handlers:
        return logger

    # Create console handler
    handler = logging.StreamHandler(sys.stdout)

    # Create JSON formatter
    formatter = CustomJsonFormatter(
        fmt='%(timestamp)s %(level)s %(name)s %(message)s',
        rename_fields={
            'levelname': 'level',
            'name': 'logger',
            'threadName': 'thread',
            'processName': 'process'
        }
    )

    handler.setFormatter(formatter)
    logger.addHandler(handler)

    return logger


# Example usage with extra fields
def log_with_context(logger: logging.Logger, message: str, **kwargs):
    """
    Log message with additional context

    Usage:
        log_with_context(logger, "Prediction made", user_id=123, model_version="v1.2")
    """
    logger.info(message, extra=kwargs)
```

**Key Features:**
- JSON output for easy parsing
- Automatic trace correlation (trace_id, span_id)
- Extra fields via `extra` parameter
- Environment and service tagging

## File 3: Request Logging Middleware

**File:** `src/monitoring/logging_middleware.py`

```python
"""
Logging Middleware
Logs all HTTP requests with structured data
"""
from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.types import ASGIApp
import time
import uuid

from src.utils.logger import get_logger


logger = get_logger(__name__)


class RequestLoggingMiddleware(BaseHTTPMiddleware):
    """Middleware to log all HTTP requests"""

    def __init__(self, app: ASGIApp):
        super().__init__(app)

    async def dispatch(self, request: Request, call_next):
        """Process request and log details"""
        # Generate request ID
        request_id = str(uuid.uuid4())
        request.state.request_id = request_id

        # Start timing
        start_time = time.time()

        # Log incoming request
        logger.info(
            "Incoming request",
            extra={
                "event": "request_started",
                "request_id": request_id,
                "method": request.method,
                "path": request.url.path,
                "query_params": dict(request.query_params),
                "client_ip": request.client.host if request.client else None,
                "user_agent": request.headers.get("user-agent")
            }
        )

        # Process request
        try:
            response = await call_next(request)

            # Calculate duration
            duration = time.time() - start_time

            # Log completed request
            logger.info(
                "Request completed",
                extra={
                    "event": "request_completed",
                    "request_id": request_id,
                    "method": request.method,
                    "path": request.url.path,
                    "status_code": response.status_code,
                    "duration_ms": round(duration * 1000, 2)
                }
            )

            # Add request ID to response headers
            response.headers["X-Request-ID"] = request_id

            return response

        except Exception as e:
            # Log errors
            duration = time.time() - start_time

            logger.error(
                "Request failed",
                extra={
                    "event": "request_failed",
                    "request_id": request_id,
                    "method": request.method,
                    "path": request.url.path,
                    "error": str(e),
                    "error_type": type(e).__name__,
                    "duration_ms": round(duration * 1000, 2)
                },
                exc_info=True
            )

            raise
```

## Powerful LogQL Queries

### Application Monitoring

```logql
# Error rate (errors per minute)
sum(rate({job="api"} |= "ERROR" [5m])) by (logger)

# Top error messages
topk(10, count_over_time({job="api"} | json | level="ERROR" [1h])) by (message)

# Requests by endpoint
sum by (path) (rate({job="api"} | json | event="request_completed" [5m]))

# Average request duration
avg_over_time({job="api"} | json | event="request_completed" | unwrap duration_ms [5m])
```

### Business Metrics

```logql
# Prediction volume
sum(rate({job="api"} | json | event="prediction_completed" [5m]))

# Default rate from logs
sum(rate({job="api"} | json | event="prediction_completed" | prediction_class="default" [5m]))
/
sum(rate({job="api"} | json | event="prediction_completed" [5m]))

# Users with errors
count(count_over_time({job="api"} | json | level="ERROR" [1h]) by (user_id))
```

### Security Monitoring

```logql
# Failed login attempts
{job="api"} | json | event="login_failed"

# Authentication errors
{job="api"} | json | level="ERROR" | message=~".*auth.*"

# Requests from specific IP
{job="api"} | json | client_ip="192.168.1.100"
```

## Log-Based Alerts in Loki

**File:** `loki/rules.yml`

```yaml
# Loki alerting rules

groups:
  - name: application_alerts
    interval: 1m
    rules:
      # High error rate
      - alert: HighErrorRate
        expr: |
          sum(rate({job="api"} |= "ERROR" [5m])) > 10
        for: 5m
        annotations:
          summary: "High error rate detected"
          description: "{{ $value }} errors per second"

      # Authentication failures
      - alert: AuthenticationFailures
        expr: |
          sum(rate({job="api"} | json | event="login_failed" [5m])) > 5
        for: 2m
        annotations:
          summary: "Multiple authentication failures"
          description: "{{ $value }} failed logins per second"

      # No predictions
      - alert: NoPredictions
        expr: |
          sum(rate({job="api"} | json | event="prediction_completed" [15m])) == 0
        for: 15m
        annotations:
          summary: "No predictions being made"
```
