**Estimated Time:** 2 hours

## Goal
Implement OpenTelemetry for comprehensive application performance monitoring (APM) with distributed tracing. Track request flows through the entire system, identify bottlenecks, visualize dependencies, and correlate traces with metrics and logs using Jaeger for trace visualization.

---

## Why OpenTelemetry & Tracing?

**Problem: Black Box Debugging**
- Logs tell you *what* happened at specific points
- Metrics show *how much* is happening
- Neither shows *why* requests are slow or the full request path

**OpenTelemetry Solution:**
- **Distributed Tracing**: Follow a request through entire system
- **Spans**: Track individual operations (database query, ML prediction, API call)
- **Context Propagation**: Link related operations across services
- **Performance Insights**: Identify slow components in request flow

**Real-World Example:**
```
User Request → API → Database → ML Model → Response
   100ms        5ms     30ms       40ms       175ms total
```

With tracing, you see:
- Database query took 30ms (17% of request)
- ML prediction took 40ms (23% of request)
- Network/serialization: 105ms (60% of request) ← investigate this!

---

## Key Concepts

### Trace & Span Hierarchy

```
Trace (full request flow)
├─ Span: HTTP Request (175ms)
   ├─ Span: Authentication (5ms)
   ├─ Span: Feature Extraction (10ms)
   ├─ Span: Database Query (30ms)
   │  └─ Span: SQL SELECT (28ms)
   ├─ Span: ML Prediction (40ms)
   │  ├─ Span: Preprocessing (8ms)
   │  └─ Span: Model Inference (32ms)
   └─ Span: Response Serialization (15ms)
```

### OpenTelemetry Components

1. **Tracer**: Creates spans for operations
2. **Span**: Represents single operation with start/end time
3. **Context**: Carries trace ID across process boundaries
4. **Exporter**: Sends telemetry data to backend (Jaeger, Prometheus)
5. **Instrumentation**: Automatic or manual span creation

### Three Pillars of Observability

- **Logs**: Discrete events ("User 123 logged in")
- **Metrics**: Aggregated measurements (requests/sec, latency p95)
- **Traces**: Request flows (how data moves through system)

**OpenTelemetry unifies all three!**

## File 1: OpenTelemetry Configuration

**File:** `src/monitoring/tracing.py`

```python
"""
OpenTelemetry Configuration
Sets up distributed tracing for the application
"""
from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor
from opentelemetry.exporter.jaeger.thrift import JaegerExporter
from opentelemetry.sdk.resources import Resource, SERVICE_NAME, SERVICE_VERSION
from opentelemetry.instrumentation.fastapi import FastAPIInstrumentor
from opentelemetry.instrumentation.sqlalchemy import SQLAlchemyInstrumentor
from opentelemetry.instrumentation.requests import RequestsInstrumentor
from opentelemetry.trace import Status, StatusCode, SpanKind
import os


class TracingConfig:
    """OpenTelemetry tracing configuration"""

    def __init__(
        self,
        service_name: str = "credit-risk-api",
        service_version: str = "1.0.0",
        jaeger_host: str = None,
        jaeger_port: int = 6831
    ):
        self.service_name = service_name
        self.service_version = service_version
        self.jaeger_host = jaeger_host or os.getenv("JAEGER_HOST", "localhost")
        self.jaeger_port = jaeger_port

        # Create resource (identifies this service)
        self.resource = Resource(attributes={
            SERVICE_NAME: self.service_name,
            SERVICE_VERSION: self.service_version,
            "environment": os.getenv("APP_ENV", "development"),
            "deployment.region": "ng-west-1"  # Example
        })

        # Set up tracer provider
        self._setup_tracer_provider()

    def _setup_tracer_provider(self):
        """Configure tracer provider with exporters"""
        # Create tracer provider
        trace_provider = TracerProvider(resource=self.resource)

        # Create Jaeger exporter
        jaeger_exporter = JaegerExporter(
            agent_host_name=self.jaeger_host,
            agent_port=self.jaeger_port,
        )

        # Add span processor (batches spans before exporting)
        span_processor = BatchSpanProcessor(jaeger_exporter)
        trace_provider.add_span_processor(span_processor)

        # Set as global tracer provider
        trace.set_tracer_provider(trace_provider)

    def instrument_app(self, app, engine=None):
        """
        Instrument FastAPI application and dependencies

        Args:
            app: FastAPI application instance
            engine: SQLAlchemy engine (optional)
        """
        # Instrument FastAPI
        FastAPIInstrumentor.instrument_app(app)

        # Instrument SQLAlchemy (if engine provided)
        if engine:
            SQLAlchemyInstrumentor().instrument(
                engine=engine,
                service=self.service_name,
                enable_commenter=True  # Add trace IDs to SQL comments
            )

        # Instrument requests library (for HTTP calls to MLflow, etc.)
        RequestsInstrumentor().instrument()

    @staticmethod
    def get_tracer(name: str = __name__):
        """Get a tracer instance"""
        return trace.get_tracer(name)


# Global tracing instance
tracing_config = None


def setup_tracing(app, engine=None):
    """
    Initialize tracing for the application

    Call this in main.py at startup
    """
    global tracing_config

    tracing_config = TracingConfig(
        service_name="credit-risk-api",
        service_version="1.0.0"
    )

    tracing_config.instrument_app(app, engine)

    return tracing_config
```

**Key Features:**
- Automatic instrumentation for FastAPI, SQLAlchemy, HTTP requests
- Batched span export (performance optimization)
- Resource attributes (identify service)
- Context propagation across async operations

## File 2: Manual Span Creation Utilities

**File:** `src/monitoring/tracing_utils.py`

```python
"""
Tracing Utilities
Helper functions for manual span creation and context
"""
from opentelemetry import trace
from opentelemetry.trace import Status, StatusCode, SpanKind
from functools import wraps
from typing import Callable, Any, Dict
import time


def traced(
    name: str = None,
    kind: SpanKind = SpanKind.INTERNAL,
    attributes: Dict[str, Any] = None
):
    """
    Decorator to trace function execution

    Usage:
        @traced("process_features")
        def process_features(data):
            ...

        @traced("database_query", kind=SpanKind.CLIENT)
        def query_database():
            ...
    """
    def decorator(func: Callable) -> Callable:
        span_name = name or f"{func.__module__}.{func.__name__}"

        @wraps(func)
        def sync_wrapper(*args, **kwargs):
            tracer = trace.get_tracer(__name__)

            with tracer.start_as_current_span(
                span_name,
                kind=kind,
                attributes=attributes or {}
            ) as span:
                try:
                    # Add function info to span
                    span.set_attribute("function.name", func.__name__)
                    span.set_attribute("function.module", func.__module__)

                    # Execute function
                    result = func(*args, **kwargs)

                    # Mark as successful
                    span.set_status(Status(StatusCode.OK))
                    return result

                except Exception as e:
                    # Record exception
                    span.record_exception(e)
                    span.set_status(Status(StatusCode.ERROR, str(e)))
                    raise

        @wraps(func)
        async def async_wrapper(*args, **kwargs):
            tracer = trace.get_tracer(__name__)

            with tracer.start_as_current_span(
                span_name,
                kind=kind,
                attributes=attributes or {}
            ) as span:
                try:
                    span.set_attribute("function.name", func.__name__)
                    span.set_attribute("function.module", func.__module__)

                    result = await func(*args, **kwargs)

                    span.set_status(Status(StatusCode.OK))
                    return result

                except Exception as e:
                    span.record_exception(e)
                    span.set_status(Status(StatusCode.ERROR, str(e)))
                    raise

        # Return appropriate wrapper
        import asyncio
        if asyncio.iscoroutinefunction(func):
            return async_wrapper
        else:
            return sync_wrapper

    return decorator


def add_span_attributes(attributes: Dict[str, Any]):
    """
    Add attributes to the current span

    Usage:
        add_span_attributes({
            "user_id": 123,
            "model_version": "v1.2.3"
        })
    """
    span = trace.get_current_span()
    if span and span.is_recording():
        for key, value in attributes.items():
            span.set_attribute(key, value)


def add_span_event(name: str, attributes: Dict[str, Any] = None):
    """
    Add an event to the current span

    Usage:
        add_span_event("cache_miss", {"key": "user_123"})
    """
    span = trace.get_current_span()
    if span and span.is_recording():
        span.add_event(name, attributes=attributes or {})


def record_exception_in_span(exception: Exception):
    """Record an exception in the current span"""
    span = trace.get_current_span()
    if span and span.is_recording():
        span.record_exception(exception)
        span.set_status(Status(StatusCode.ERROR, str(exception)))
```

## File 6: Custom Tracing for Batch Predictions

**File:** Update `src/models/batch_predict.py`

```python
from src.monitoring.tracing_utils import traced, add_span_attributes, add_span_event
from opentelemetry import trace

@traced("batch_prediction", kind=SpanKind.INTERNAL)
def predict_batch(features_list: list, model_version: str = "default"):
    """
    Make batch predictions with detailed tracing

    Args:
        features_list: List of feature dictionaries
        model_version: Model version to use

    Returns:
        List of predictions
    """
    tracer = trace.get_tracer(__name__)

    # Add batch info to span
    add_span_attributes({
        "batch_size": len(features_list),
        "model_version": model_version
    })

    predictions = []

    # Process in chunks (with child spans)
    chunk_size = 1000
    for i in range(0, len(features_list), chunk_size):
        chunk = features_list[i:i + chunk_size]

        # Create child span for each chunk
        with tracer.start_as_current_span(
            f"process_chunk_{i//chunk_size}",
            attributes={
                "chunk_index": i // chunk_size,
                "chunk_size": len(chunk)
            }
        ) as chunk_span:
            chunk_predictions = process_chunk(chunk, model_version)
            predictions.extend(chunk_predictions)

            add_span_event("chunk_completed", {
                "predictions_count": len(chunk_predictions)
            })

    # Add summary to parent span
    add_span_attributes({
        "total_predictions": len(predictions),
        "default_count": sum(1 for p in predictions if p >= 0.5),
        "default_rate": sum(1 for p in predictions if p >= 0.5) / len(predictions)
    })

    return predictions
```

## Advanced Tracing Features

### Trace Context Propagation (Microservices)

If calling another service:

```python
from opentelemetry import trace
from opentelemetry.propagate import inject
import requests

def call_external_service():
    """Call external service with trace context"""
    tracer = trace.get_tracer(__name__)

    with tracer.start_as_current_span("external_api_call"):
        headers = {}

        # Inject trace context into headers
        inject(headers)

        # Make request with trace headers
        response = requests.get(
            "http://other-service/api/endpoint",
            headers=headers
        )

        return response.json()
```

### Baggage (Cross-Cutting Concerns)

Attach data that flows through entire trace:

```python
from opentelemetry import baggage

# Set baggage (available in all child spans)
ctx = baggage.set_baggage("user_id", "12345")
ctx = baggage.set_baggage("tenant", "acme_corp", context=ctx)

# Get baggage in any span
user_id = baggage.get_baggage("user_id")
```

## Common Issues & Solutions

### Issue 1: No traces appearing in Jaeger

**Check:**
```bash
# Verify Jaeger is running
curl http://localhost:16686/api/services

# Check application logs for export errors
docker logs credit_risk_api | grep -i trace
```

**Solution:**
- Ensure `JAEGER_HOST` points to correct hostname
- Check network connectivity
- Verify spans are being created (add logs)

### Issue 2: Traces incomplete or missing spans

**Cause:** Context not propagated in async code

**Solution:** Use `@traced` decorator or manual context management:
```python
from opentelemetry import context

# Save context
ctx = context.get_current()

# In async function
await asyncio.sleep(1)
# Context is preserved automatically by OpenTelemetry
```

### Issue 3: High overhead from tracing

**Solutions:**
1. Enable sampling (trace only 10%):
   ```python
   sampler = ParentBasedTraceIdRatio(0.1)
   ```

2. Use batch span processor (already configured)

3. Adjust batch size:
   ```python
   from opentelemetry.sdk.trace.export import BatchSpanProcessor

   processor = BatchSpanProcessor(
       exporter,
       max_queue_size=2048,
       max_export_batch_size=512
   )
   ```
