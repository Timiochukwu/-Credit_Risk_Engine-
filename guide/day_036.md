Today you'll add advanced explainability features to your Credit Risk Engine. You'll implement SHAP (SHapley Additive exPlanations) for model interpretation, build feature importance visualizations, create a what-if analysis tool, and generate model cards for transparency.

## Why Explainability?

**Problem**: Black-box ML models create issues:
- **Regulatory compliance**: Basel III, GDPR require explainable decisions
- **Trust**: Customers and loan officers don't trust unexplained rejections
- **Debugging**: Hard to identify why model makes errors
- **Bias detection**: Can't detect unfair patterns without transparency
- **Business insights**: Can't learn what drives credit risk

**Solution**: Explainability provides:
- **SHAP values**: Show contribution of each feature to a prediction
- **Feature importance**: Identify most influential factors
- **What-if analysis**: Test scenarios ("What if income was $10k higher?")
- **Model cards**: Document model behavior and limitations

**Benefits**:
- **Regulatory compliance**: Meet explainability requirements
- **User trust**: Transparent decisions build confidence
- **Better models**: Understand and improve model behavior
- **Fairness**: Detect and mitigate bias
- **Business value**: Extract insights from predictions

### Step 2: Create SHAP Explainer

**`app/explainability/shap_explainer.py`**:

```python
import shap
import numpy as np
import pandas as pd
from typing import Dict, List, Any
import pickle
import logging

logger = logging.getLogger(__name__)


class SHAPExplainer:
    """SHAP-based model explainer for credit risk predictions."""

    def __init__(self, model_path: str, feature_names: List[str]):
        """
        Initialize SHAP explainer.

        Args:
            model_path: Path to trained model pickle file
            feature_names: List of feature names in order
        """
        self.feature_names = feature_names

        # Load model
        with open(model_path, 'rb') as f:
            self.model = pickle.load(f)

        # Create SHAP explainer
        # For tree-based models (XGBoost, RandomForest, etc.)
        self.explainer = shap.TreeExplainer(self.model)

        logger.info("SHAP explainer initialized")

    def explain_prediction(
        self,
        features: pd.DataFrame
    ) -> Dict[str, Any]:
        """
        Generate SHAP explanation for a single prediction.

        Args:
            features: DataFrame with single row of features

        Returns:
            Dictionary with SHAP values and base explanation
        """
        # Calculate SHAP values
        shap_values = self.explainer.shap_values(features)

        # Get base value (average prediction)
        base_value = self.explainer.expected_value

        # For binary classification, shap_values might be 2D
        if isinstance(shap_values, list):
            shap_values = shap_values[1]  # Use positive class

        # Create feature contributions
        contributions = []
        for i, feature_name in enumerate(self.feature_names):
            contributions.append({
                'feature': feature_name,
                'value': float(features.iloc[0, i]),
                'shap_value': float(shap_values[0, i]),
                'contribution': 'increases' if shap_values[0, i] > 0 else 'decreases'
            })

        # Sort by absolute SHAP value
        contributions.sort(key=lambda x: abs(x['shap_value']), reverse=True)

        return {
            'base_value': float(base_value),
            'prediction': float(self.model.predict_proba(features)[0, 1]),
            'contributions': contributions,
            'top_factors': contributions[:5]  # Top 5 features
        }

    def get_feature_importance(
        self,
        X: pd.DataFrame,
        max_samples: int = 1000
    ) -> List[Dict[str, Any]]:
        """
        Calculate global feature importance using SHAP.

        Args:
            X: DataFrame with features
            max_samples: Maximum samples to use (for speed)

        Returns:
            List of features with importance scores
        """
        # Sample data if too large
        if len(X) > max_samples:
            X_sample = X.sample(n=max_samples, random_state=42)
        else:
            X_sample = X

        # Calculate SHAP values
        shap_values = self.explainer.shap_values(X_sample)

        if isinstance(shap_values, list):
            shap_values = shap_values[1]  # Positive class

        # Calculate mean absolute SHAP values
        importance = np.abs(shap_values).mean(axis=0)

        # Create feature importance list
        feature_importance = []
        for i, feature_name in enumerate(self.feature_names):
            feature_importance.append({
                'feature': feature_name,
                'importance': float(importance[i])
            })

        # Sort by importance
        feature_importance.sort(key=lambda x: x['importance'], reverse=True)

        return feature_importance

    def generate_summary_data(
        self,
        X: pd.DataFrame,
        max_samples: int = 100
    ) -> Dict[str, Any]:
        """
        Generate data for SHAP summary plot.

        Args:
            X: DataFrame with features
            max_samples: Maximum samples to use

        Returns:
            Dictionary with SHAP values and features
        """
        if len(X) > max_samples:
            X_sample = X.sample(n=max_samples, random_state=42)
        else:
            X_sample = X

        shap_values = self.explainer.shap_values(X_sample)

        if isinstance(shap_values, list):
            shap_values = shap_values[1]

        return {
            'shap_values': shap_values.tolist(),
            'features': X_sample.values.tolist(),
            'feature_names': self.feature_names
        }
```

### Step 1: Create What-If Analyzer

**`app/explainability/whatif.py`**:

```python
import pandas as pd
from typing import Dict, List, Any
import pickle


class WhatIfAnalyzer:
    """What-if analysis tool for exploring prediction scenarios."""

    def __init__(self, model_path: str, feature_names: List[str]):
        self.feature_names = feature_names

        with open(model_path, 'rb') as f:
            self.model = pickle.load(f)

    def analyze_scenarios(
        self,
        base_features: Dict[str, Any],
        scenarios: List[Dict[str, Any]]
    ) -> Dict[str, Any]:
        """
        Analyze multiple what-if scenarios.

        Args:
            base_features: Original feature values
            scenarios: List of feature modifications to test

        Returns:
            Results showing prediction changes for each scenario
        """
        from app.ml.preprocessing import preprocess_features

        # Get base prediction
        base_processed = preprocess_features(base_features)
        base_df = pd.DataFrame([base_processed])
        base_pred = float(self.model.predict_proba(base_df)[0, 1])

        results = []

        for i, scenario in enumerate(scenarios):
            # Merge scenario with base features
            modified = {**base_features, **scenario['changes']}

            # Get prediction for modified features
            modified_processed = preprocess_features(modified)
            modified_df = pd.DataFrame([modified_processed])
            modified_pred = float(self.model.predict_proba(modified_df)[0, 1])

            # Calculate change
            change = modified_pred - base_pred
            change_pct = (change / base_pred * 100) if base_pred > 0 else 0

            results.append({
                'scenario': scenario.get('name', f'Scenario {i+1}'),
                'changes': scenario['changes'],
                'original_risk': base_pred,
                'modified_risk': modified_pred,
                'risk_change': change,
                'risk_change_percent': change_pct
            })

        return {
            'base_risk': base_pred,
            'scenarios': results
        }

    def feature_sensitivity(
        self,
        base_features: Dict[str, Any],
        feature: str,
        values: List[Any]
    ) -> Dict[str, Any]:
        """
        Analyze sensitivity of prediction to a single feature.

        Args:
            base_features: Original feature values
            feature: Feature to vary
            values: Different values to test

        Returns:
            Predictions for each value of the feature
        """
        from app.ml.preprocessing import preprocess_features

        results = []

        for value in values:
            # Modify feature
            modified = {**base_features, feature: value}

            # Get prediction
            modified_processed = preprocess_features(modified)
            modified_df = pd.DataFrame([modified_processed])
            pred = float(self.model.predict_proba(modified_df)[0, 1])

            results.append({
                'value': value,
                'risk': pred
            })

        return {
            'feature': feature,
            'sensitivity': results
        }
```

## Best Practices

### 1. Cache SHAP Explainer

SHAP initialization is expensive. Cache it:

```python
from functools import lru_cache

@lru_cache(maxsize=1)
def get_explainer():
    return SHAPExplainer(model_path, feature_names)
```

### 2. Limit Sample Size for Performance

```python
# Use max_samples to limit computation
shap_values = explainer.shap_values(X.sample(n=1000))
```

### 3. Provide Human-Readable Explanations

```python
# Convert SHAP values to plain language
if shap_value > 0:
    explanation = f"{feature} increases default risk by {abs(shap_value):.2%}"
else:
    explanation = f"{feature} decreases default risk by {abs(shap_value):.2%}"
```

### 4. Document Model Card Regularly

Update model card when:
- Model is retrained
- Performance changes significantly
- New biases are discovered
- Intended use changes

### 5. Validate Explanations

```python
# Ensure SHAP values sum to prediction difference
assert abs(sum(shap_values) - (prediction - base_value)) < 0.01
```
