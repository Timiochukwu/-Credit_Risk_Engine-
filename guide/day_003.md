## Step 5: Create Database Models

**File:** `src/models/database_models.py`

```python
"""
SQLAlchemy ORM models for database tables.
"""

from sqlalchemy import Column, Integer, String, Float, DateTime, Enum
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.sql import func
import enum

Base = declarative_base()


class EmploymentStatus(str, enum.Enum):
    """Employment status enum."""
    EMPLOYED = "EMPLOYED"
    SELF_EMPLOYED = "SELF_EMPLOYED"
    UNEMPLOYED = "UNEMPLOYED"


class RiskCategory(str, enum.Enum):
    """Risk category enum."""
    VERY_LOW = "VERY_LOW"
    LOW = "LOW"
    MEDIUM = "MEDIUM"
    HIGH = "HIGH"
    VERY_HIGH = "VERY_HIGH"


class LoanApplication(Base):
    """
    Loan application database model.

    Stores all loan applications and their risk assessments.
    """
    __tablename__ = "loan_applications"

    # Primary key
    id = Column(Integer, primary_key=True, index=True, autoincrement=True)

    # Applicant information
    applicant_name = Column(String(100), nullable=False, index=True)
    age = Column(Integer, nullable=False)
    employment_status = Column(Enum(EmploymentStatus), nullable=False)
    monthly_income = Column(Float, nullable=False)

    # Loan details
    loan_amount = Column(Float, nullable=False)
    loan_purpose = Column(String(200), nullable=True)

    # Risk assessment (populated after prediction)
    predicted_risk = Column(Enum(RiskCategory), nullable=True)
    risk_score = Column(Float, nullable=True)
    recommendation = Column(String(500), nullable=True)

    # Timestamps
    created_at = Column(DateTime(timezone=True), server_default=func.now(), nullable=False)
    updated_at = Column(DateTime(timezone=True), onupdate=func.now())

    def __repr__(self):
        return f"<LoanApplication(id={self.id}, name={self.applicant_name}, risk={self.predicted_risk})>"
```

**SQLAlchemy Concepts Explained:**

1. **Base = declarative_base():** Creates base class for all models
2. **Column():** Defines a table column
3. **Integer, String, Float, DateTime:** Column data types
4. **primary_key=True:** Unique identifier for each row
5. **index=True:** Creates database index for faster queries
6. **nullable=False:** Field is required
7. **Enum():** Restricts values to predefined options
8. **server_default=func.now():** Database sets timestamp automatically
9. **onupdate=func.now():** Auto-update timestamp on changes

## Step 6: Create Database Connection

**File:** `src/utils/database.py`

```python
"""
Database connection and session management.
"""

from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, Session
from contextlib import contextmanager
from typing import Generator

from src.utils.config import settings
from src.utils.logger import logger

# Create database engine
engine = create_engine(
    settings.database_url,
    echo=settings.db_echo,  # Log SQL queries (useful for debugging)
    pool_size=5,            # Connection pool size
    max_overflow=10,        # Max connections beyond pool_size
    pool_pre_ping=True      # Verify connections before using
)

# Create session factory
SessionLocal = sessionmaker(
    autocommit=False,
    autoflush=False,
    bind=engine
)


def get_db() -> Generator[Session, None, None]:
    """
    Dependency to get database session.

    Yields:
        Database session

    Usage in FastAPI:
        @app.get("/items")
        def read_items(db: Session = Depends(get_db)):
            ...
    """
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()


@contextmanager
def get_db_context():
    """
    Context manager for database session.

    Usage:
        with get_db_context() as db:
            db.query(Model).all()
    """
    db = SessionLocal()
    try:
        yield db
        db.commit()
    except Exception as e:
        db.rollback()
        logger.error(f"Database error: {e}")
        raise
    finally:
        db.close()


def init_db():
    """
    Initialize database tables.
    Creates all tables defined in models.
    """
    from src.models.database_models import Base

    logger.info("Creating database tables...")
    Base.metadata.create_all(bind=engine)
    logger.info("Database tables created successfully")


def drop_db():
    """
    Drop all database tables (use with caution!).
    """
    from src.models.database_models import Base

    logger.warning("Dropping all database tables...")
    Base.metadata.drop_all(bind=engine)
    logger.info("Database tables dropped")
```

**Database Concepts Explained:**

1. **create_engine():** Manages connection to database
2. **pool_size:** Number of persistent connections to maintain
3. **pool_pre_ping:** Check if connection is alive before using
4. **sessionmaker():** Factory for creating database sessions
5. **autocommit=False:** Manual transaction control
6. **yield:** Generator pattern for dependency injection in FastAPI
7. **Context manager:** Automatic cleanup with `with` statement

```python
"""
Pydantic schemas for request/response validation.
"""

from pydantic import BaseModel, Field
from typing import Literal, Optional
from datetime import datetime


class HealthResponse(BaseModel):
    """Response schema for health check endpoint."""
    status: str
    timestamp: datetime
    version: str


class LoanApplicationRequest(BaseModel):
    """Schema for loan application prediction request."""

    applicant_name: str = Field(..., min_length=2, max_length=100)
    loan_amount: float = Field(..., gt=0, le=100_000_000)
    monthly_income: float = Field(..., gt=0)
    employment_status: Literal["EMPLOYED", "SELF_EMPLOYED", "UNEMPLOYED"]
    age: int = Field(..., ge=18, le=100)
    loan_purpose: Optional[str] = Field(None, max_length=200)

    class Config:
        json_schema_extra = {
            "example": {
                "applicant_name": "Adebayo Johnson",
                "loan_amount": 5000000,
                "monthly_income": 500000,
                "employment_status": "EMPLOYED",
                "age": 35,
                "loan_purpose": "Business expansion"
            }
        }


class PredictionResponse(BaseModel):
    """Response schema for prediction endpoint."""

    applicant_name: str
    loan_amount: float
    predicted_risk: Literal["VERY_LOW", "LOW", "MEDIUM", "HIGH", "VERY_HIGH"]
    risk_score: float = Field(..., ge=0.0, le=1.0)
    recommendation: str
    timestamp: datetime


class LoanApplicationResponse(BaseModel):
    """Response schema for loan application database record."""

    id: int
    applicant_name: str
    age: int
    employment_status: str
    monthly_income: float
    loan_amount: float
    loan_purpose: Optional[str]
    predicted_risk: Optional[str]
    risk_score: Optional[float]
    recommendation: Optional[str]
    created_at: datetime
    updated_at: Optional[datetime]

    class Config:
        from_attributes = True  # Allows conversion from ORM models
```

## Step 8: Update Main API with Database Endpoints

**Update:** `src/api/main.py`

```python
"""
Main FastAPI application for Nigerian Credit Risk Engine.
"""

from fastapi import FastAPI, HTTPException, Depends
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session
from datetime import datetime
from typing import List
import random

from src.utils.config import settings
from src.utils.logger import logger
from src.utils.database import get_db, init_db
from src.models.database_models import LoanApplication, EmploymentStatus, RiskCategory
from src.api.schemas import (
    HealthResponse,
    LoanApplicationRequest,
    PredictionResponse,
    LoanApplicationResponse
)

# Initialize FastAPI app
app = FastAPI(
    title=settings.project_name,
    version=settings.version,
    description="Machine Learning API for Credit Risk Assessment",
    docs_url="/docs",
    redoc_url="/redoc"
)

# Add CORS middleware
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.on_event("startup")
async def startup_event():
    """Run on application startup."""
    logger.info(f"Starting {settings.project_name} v{settings.version}")
    logger.info(f"Debug mode: {settings.debug}")
    init_db()  # Create tables if they don't exist


@app.on_event("shutdown")
async def shutdown_event():
    """Run on application shutdown."""
    logger.info("Shutting down API")


@app.get("/", tags=["Root"])
async def root():
    """Root endpoint with API information."""
    return {
        "name": settings.project_name,
        "version": settings.version,
        "status": "running",
        "docs": "/docs",
        "health": "/health"
    }


@app.get("/health", response_model=HealthResponse, tags=["Health"])
async def health_check():
    """Health check endpoint."""
    logger.debug("Health check requested")
    return HealthResponse(
        status="healthy",
        timestamp=datetime.utcnow(),
        version=settings.version
    )


@app.post("/api/v1/predict", response_model=PredictionResponse, tags=["Predictions"])
async def predict_loan_risk(
    application: LoanApplicationRequest,
    db: Session = Depends(get_db)
):
    """
    Predict loan default risk and save to database.
    """
    logger.info(f"Prediction requested for {application.applicant_name}")

    # Mock prediction logic (same as before)
    debt_to_income = application.loan_amount / (application.monthly_income * 12)
    base_risk = min(debt_to_income / 10, 0.9)
    risk_score = base_risk + random.uniform(-0.1, 0.1)
    risk_score = max(0.0, min(1.0, risk_score))

    if risk_score < 0.2:
        risk_category = RiskCategory.VERY_LOW
        recommendation = "APPROVE - Excellent candidate"
    elif risk_score < 0.4:
        risk_category = RiskCategory.LOW
        recommendation = "APPROVE - Good candidate"
    elif risk_score < 0.6:
        risk_category = RiskCategory.MEDIUM
        recommendation = "REVIEW - Manual review recommended"
    elif risk_score < 0.8:
        risk_category = RiskCategory.HIGH
        recommendation = "REJECT - High risk of default"
    else:
        risk_category = RiskCategory.VERY_HIGH
        recommendation = "REJECT - Very high risk"

    # Save to database
    db_application = LoanApplication(
        applicant_name=application.applicant_name,
        age=application.age,
        employment_status=EmploymentStatus(application.employment_status),
        monthly_income=application.monthly_income,
        loan_amount=application.loan_amount,
        loan_purpose=application.loan_purpose,
        predicted_risk=risk_category,
        risk_score=round(risk_score, 3),
        recommendation=recommendation
    )

    db.add(db_application)
    db.commit()
    db.refresh(db_application)

    logger.info(f"Application saved with ID: {db_application.id}")

    return PredictionResponse(
        applicant_name=application.applicant_name,
        loan_amount=application.loan_amount,
        predicted_risk=risk_category.value,
        risk_score=round(risk_score, 3),
        recommendation=recommendation,
        timestamp=datetime.utcnow()
    )


@app.get("/api/v1/applications", response_model=List[LoanApplicationResponse], tags=["Applications"])
async def get_all_applications(
    skip: int = 0,
    limit: int = 100,
    db: Session = Depends(get_db)
):
    """
    Retrieve all loan applications with pagination.

    - skip: Number of records to skip
    - limit: Maximum number of records to return
    """
    applications = db.query(LoanApplication).offset(skip).limit(limit).all()
    logger.info(f"Retrieved {len(applications)} applications")
    return applications


@app.get("/api/v1/applications/{application_id}", response_model=LoanApplicationResponse, tags=["Applications"])
async def get_application(
    application_id: int,
    db: Session = Depends(get_db)
):
    """Retrieve a specific loan application by ID."""
    application = db.query(LoanApplication).filter(LoanApplication.id == application_id).first()

    if not application:
        raise HTTPException(status_code=404, detail=f"Application {application_id} not found")

    return application
```

**New Concepts:**

1. **Depends(get_db):** Dependency injection - FastAPI automatically provides database session
2. **db.add():** Add record to session
3. **db.commit():** Save changes to database
4. **db.refresh():** Reload object from database (gets auto-generated ID)
5. **db.query(Model):** Start a database query
6. **offset/limit:** Pagination (skip N records, return M records)

## Understanding SQL vs ORM

**Raw SQL:**
```sql
INSERT INTO loan_applications (applicant_name, loan_amount)
VALUES ('John Doe', 5000000);
```

**SQLAlchemy ORM:**
```python
app = LoanApplication(applicant_name="John Doe", loan_amount=5000000)
db.add(app)
db.commit()
```

**Benefits of ORM:**
- Type safety
- Python-native code
- Automatic query generation
- Protection against SQL injection
- Database-agnostic (can switch from PostgreSQL to MySQL with minimal changes)

## Troubleshooting

**Issue:** `psycopg2.OperationalError: FATAL: password authentication failed`
**Solution:** Check DATABASE_URL in .env matches your PostgreSQL user/password

**Issue:** `permission denied for schema public`
**Solution:** Grant schema privileges: `GRANT ALL ON SCHEMA public TO credit_user;`

**Issue:** Tables not created
**Solution:** Check logs for errors, verify `init_db()` is called in startup event

**Issue:** `sqlalchemy.exc.IntegrityError`
**Solution:** Violating a database constraint (e.g., null in required field)
