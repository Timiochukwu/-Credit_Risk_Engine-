## Understanding Model Monitoring

**What is model drift?**
When the relationship between features and target changes over time, causing model performance to degrade.

**Types of drift:**

1. **Data Drift (Covariate Shift):**
   - Input features change distribution
   - Example: Average loan amount increases from ₦5M to ₦8M
   - Model still works, but operates in different range

2. **Prediction Drift:**
   - Model outputs change distribution
   - Example: Suddenly predicting 50% defaults instead of 30%
   - Warning sign something changed

3. **Concept Drift:**
   - Relationship between features and target changes
   - Example: Economic crisis makes predictions less accurate
   - Most serious - requires retraining

**Why monitor?**
- Detect when model needs retraining
- Catch data quality issues early
- Ensure production performance
- Regulatory compliance (audit trail)

## Step 2: Create Drift Detection Module

**File:** `src/monitoring/drift_detector.py`

```python
"""
Data and prediction drift detection.
"""

import pandas as pd
import numpy as np
from scipy import stats
from typing import Dict, List, Tuple, Optional
from pathlib import Path
import json
from datetime import datetime

from src.utils.logger import logger


class DriftDetector:
    """
    Detects drift in data and predictions.

    Uses statistical tests to compare reference (training) data
    with production data.
    """

    def __init__(self, reference_data: Optional[pd.DataFrame] = None):
        """
        Initialize drift detector.

        Args:
            reference_data: Training/reference data to compare against
        """
        self.reference_data = reference_data
        self.drift_threshold = 0.05  # p-value threshold (5% significance)

    def load_reference_data(self):
        """Load training data as reference."""
        logger.info("Loading reference data (training set)...")

        X_train = pd.read_csv("data/processed/X_train.csv")
        y_train = pd.read_csv("data/processed/y_train.csv")

        self.reference_data = X_train.copy()
        self.reference_data['target'] = y_train['defaulted']

        logger.info(f"Reference data loaded: {len(self.reference_data)} samples")

    def kolmogorov_smirnov_test(
        self,
        reference: np.ndarray,
        production: np.ndarray
    ) -> Tuple[float, float]:
        """
        Perform Kolmogorov-Smirnov test for numerical features.

        Tests if two samples come from the same distribution.

        Args:
            reference: Reference (training) feature values
            production: Production feature values

        Returns:
            (statistic, p_value) where p_value < 0.05 indicates drift
        """
        statistic, p_value = stats.ks_2samp(reference, production)
        return statistic, p_value

    def chi_square_test(
        self,
        reference: np.ndarray,
        production: np.ndarray
    ) -> Tuple[float, float]:
        """
        Perform Chi-square test for categorical features.

        Args:
            reference: Reference category counts
            production: Production category counts

        Returns:
            (statistic, p_value) where p_value < 0.05 indicates drift
        """
        # Get value counts
        ref_counts = pd.Series(reference).value_counts()
        prod_counts = pd.Series(production).value_counts()

        # Align indices
        all_categories = set(ref_counts.index) | set(prod_counts.index)
        ref_counts = ref_counts.reindex(all_categories, fill_value=0)
        prod_counts = prod_counts.reindex(all_categories, fill_value=0)

        # Perform chi-square test
        statistic, p_value = stats.chisquare(prod_counts, ref_counts)

        return statistic, p_value

    def detect_feature_drift(
        self,
        production_data: pd.DataFrame,
        feature_name: str
    ) -> Dict:
        """
        Detect drift for a single feature.

        Args:
            production_data: Current production data
            feature_name: Name of feature to check

        Returns:
            Dictionary with drift detection results
        """
        if self.reference_data is None:
            self.load_reference_data()

        reference_values = self.reference_data[feature_name].values
        production_values = production_data[feature_name].values

        # Determine feature type
        is_numerical = pd.api.types.is_numeric_dtype(production_data[feature_name])

        if is_numerical:
            # Use KS test for numerical features
            statistic, p_value = self.kolmogorov_smirnov_test(
                reference_values,
                production_values
            )
            test_used = "Kolmogorov-Smirnov"
        else:
            # Use Chi-square for categorical
            statistic, p_value = self.chi_square_test(
                reference_values,
                production_values
            )
            test_used = "Chi-Square"

        # Determine if drift detected
        drift_detected = p_value < self.drift_threshold

        # Calculate distribution statistics
        ref_mean = reference_values.mean() if is_numerical else None
        prod_mean = production_values.mean() if is_numerical else None

        result = {
            'feature': feature_name,
            'test_used': test_used,
            'statistic': float(statistic),
            'p_value': float(p_value),
            'drift_detected': bool(drift_detected),
            'threshold': self.drift_threshold,
            'reference_mean': float(ref_mean) if ref_mean is not None else None,
            'production_mean': float(prod_mean) if prod_mean is not None else None,
            'mean_shift': float(prod_mean - ref_mean) if prod_mean is not None else None
        }

        return result

    def detect_dataset_drift(
        self,
        production_data: pd.DataFrame,
        features: Optional[List[str]] = None
    ) -> Dict:
        """
        Detect drift across multiple features.

        Args:
            production_data: Current production data
            features: List of features to check (None = all)

        Returns:
            Dictionary with drift results for all features
        """
        if self.reference_data is None:
            self.load_reference_data()

        if features is None:
            # Use all features except target
            features = [col for col in production_data.columns if col != 'target']

        logger.info(f"Checking drift for {len(features)} features...")

        results = {
            'timestamp': datetime.utcnow().isoformat(),
            'total_features': len(features),
            'features_with_drift': 0,
            'feature_results': []
        }

        for feature in features:
            if feature not in self.reference_data.columns:
                logger.warning(f"Feature '{feature}' not in reference data, skipping")
                continue

            try:
                feature_result = self.detect_feature_drift(production_data, feature)
                results['feature_results'].append(feature_result)

                if feature_result['drift_detected']:
                    results['features_with_drift'] += 1
                    logger.warning(
                        f"⚠️  DRIFT DETECTED: {feature} "
                        f"(p-value: {feature_result['p_value']:.4f})"
                    )

            except Exception as e:
                logger.error(f"Error checking drift for {feature}: {e}")

        drift_percentage = (results['features_with_drift'] / len(features)) * 100

        logger.info(
            f"Drift detection complete: {results['features_with_drift']}/{len(features)} "
            f"features ({drift_percentage:.1f}%) show drift"
        )

        results['drift_percentage'] = drift_percentage

        return results

    def detect_prediction_drift(
        self,
        reference_predictions: np.ndarray,
        production_predictions: np.ndarray
    ) -> Dict:
        """
        Detect drift in model predictions.

        Args:
            reference_predictions: Training set predictions
            production_predictions: Production predictions

        Returns:
            Drift analysis results
        """
        logger.info("Detecting prediction drift...")

        # KS test on prediction probabilities
        statistic, p_value = self.kolmogorov_smirnov_test(
            reference_predictions,
            production_predictions
        )

        drift_detected = p_value < self.drift_threshold

        # Calculate distribution changes
        ref_mean = reference_predictions.mean()
        prod_mean = production_predictions.mean()
        mean_shift = prod_mean - ref_mean

        ref_std = reference_predictions.std()
        prod_std = production_predictions.std()

        result = {
            'test_used': 'Kolmogorov-Smirnov',
            'statistic': float(statistic),
            'p_value': float(p_value),
            'drift_detected': bool(drift_detected),
            'threshold': self.drift_threshold,
            'reference_mean': float(ref_mean),
            'production_mean': float(prod_mean),
            'mean_shift': float(mean_shift),
            'reference_std': float(ref_std),
            'production_std': float(prod_std),
            'timestamp': datetime.utcnow().isoformat()
        }

        if drift_detected:
            logger.warning(
                f"⚠️  PREDICTION DRIFT DETECTED! "
                f"Mean shifted from {ref_mean:.3f} to {prod_mean:.3f}"
            )
        else:
            logger.info(f"✓ No prediction drift detected (p-value: {p_value:.4f})")

        return result


def save_drift_report(results: Dict, output_dir: str = "data/monitoring"):
    """
    Save drift detection results to JSON file.

    Args:
        results: Drift detection results
        output_dir: Directory to save reports
    """
    output_path = Path(output_dir)
    output_path.mkdir(parents=True, exist_ok=True)

    timestamp = datetime.utcnow().strftime('%Y%m%d_%H%M%S')
    filename = output_path / f"drift_report_{timestamp}.json"

    with open(filename, 'w') as f:
        json.dump(results, f, indent=2)

    logger.info(f"Drift report saved to {filename}")


def main():
    """
    Example: Detect drift using test set as "production" data.
    """
    logger.info("=" * 60)
    logger.info("DRIFT DETECTION EXAMPLE")
    logger.info("=" * 60)

    # Load test data as "production" data
    X_test = pd.read_csv("data/processed/X_test.csv")

    # Create drift detector
    detector = DriftDetector()

    # Detect drift
    results = detector.detect_dataset_drift(X_test)

    # Save report
    save_drift_report(results)

    # Print summary
    logger.info("\n" + "=" * 60)
    logger.info("DRIFT DETECTION SUMMARY")
    logger.info("=" * 60)
    logger.info(f"Total features checked: {results['total_features']}")
    logger.info(f"Features with drift: {results['features_with_drift']}")
    logger.info(f"Drift percentage: {results['drift_percentage']:.1f}%")

    if results['features_with_drift'] > 0:
        logger.info("\nFeatures with significant drift:")
        for feature_result in results['feature_results']:
            if feature_result['drift_detected']:
                logger.info(
                    f"  - {feature_result['feature']}: "
                    f"p-value={feature_result['p_value']:.4f}"
                )

    logger.info("=" * 60)


if __name__ == "__main__":
    main()
```

**Drift Detection Concepts:**

1. **Kolmogorov-Smirnov (KS) Test:**
   - Compares two distributions
   - Works for continuous features
   - Returns p-value (< 0.05 = significant difference)

2. **Chi-Square Test:**
   - Compares categorical distributions
   - Tests if category proportions changed

3. **P-value:**
   - Probability that difference is due to chance
   - < 0.05 = statistically significant (drift detected)

4. **Statistical Significance:**
   - 95% confidence level (p < 0.05)
   - Industry standard

```python
"""
Production monitoring and metrics tracking.
"""

import pandas as pd
import numpy as np
from pathlib import Path
from datetime import datetime
import json

from src.utils.logger import logger


class ProductionMonitor:
    """
    Tracks production predictions and performance.
    """

    def __init__(self, storage_dir: str = "data/monitoring"):
        self.storage_dir = Path(storage_dir)
        self.storage_dir.mkdir(parents=True, exist_ok=True)

        self.predictions_file = self.storage_dir / "production_predictions.csv"
        self.metrics_file = self.storage_dir / "production_metrics.json"

    def log_prediction(
        self,
        application_id: str,
        features: Dict,
        prediction: int,
        probability: float,
        model_version: str = "xgboost_v1"
    ):
        """
        Log a production prediction.

        Args:
            application_id: Unique identifier
            features: Input features (subset for monitoring)
            prediction: Model prediction (0 or 1)
            probability: Prediction probability
            model_version: Model version used
        """
        record = {
            'timestamp': datetime.utcnow().isoformat(),
            'application_id': application_id,
            'prediction': prediction,
            'probability': probability,
            'model_version': model_version,
            **features  # Add selected features
        }

        # Append to CSV
        df = pd.DataFrame([record])

        if self.predictions_file.exists():
            df.to_csv(self.predictions_file, mode='a', header=False, index=False)
        else:
            df.to_csv(self.predictions_file, index=False)

    def log_batch_predictions(
        self,
        predictions_df: pd.DataFrame,
        model_version: str = "xgboost_v1"
    ):
        """
        Log batch predictions.

        Args:
            predictions_df: DataFrame with predictions
            model_version: Model version
        """
        predictions_df['timestamp'] = datetime.utcnow().isoformat()
        predictions_df['model_version'] = model_version

        if self.predictions_file.exists():
            predictions_df.to_csv(self.predictions_file, mode='a', header=False, index=False)
        else:
            predictions_df.to_csv(self.predictions_file, index=False)

        logger.info(f"Logged {len(predictions_df)} batch predictions")

    def get_recent_predictions(self, n: int = 1000) -> pd.DataFrame:
        """
        Get recent production predictions.

        Args:
            n: Number of recent predictions to retrieve

        Returns:
            DataFrame with recent predictions
        """
        if not self.predictions_file.exists():
            logger.warning("No production predictions logged yet")
            return pd.DataFrame()

        df = pd.read_csv(self.predictions_file)

        # Return last N rows
        return df.tail(n)

    def calculate_prediction_statistics(self) -> Dict:
        """
        Calculate statistics on production predictions.

        Returns:
            Dictionary with statistics
        """
        if not self.predictions_file.exists():
            return {}

        df = pd.read_csv(self.predictions_file)

        stats = {
            'total_predictions': len(df),
            'date_range': {
                'start': df['timestamp'].min(),
                'end': df['timestamp'].max()
            },
            'prediction_distribution': {
                'no_default': int((df['prediction'] == 0).sum()),
                'default': int((df['prediction'] == 1).sum()),
                'default_rate': float(df['prediction'].mean())
            },
            'probability_stats': {
                'mean': float(df['probability'].mean()),
                'median': float(df['probability'].median()),
                'std': float(df['probability'].std()),
                'min': float(df['probability'].min()),
                'max': float(df['probability'].max())
            }
        }

        return stats

    def save_metrics(self, metrics: Dict):
        """Save metrics to JSON file."""
        with open(self.metrics_file, 'w') as f:
            json.dump(metrics, f, indent=2)

        logger.info(f"Metrics saved to {self.metrics_file}")


def main():
    """Example monitoring usage."""
    logger.info("Initializing production monitor...")

    monitor = ProductionMonitor()

    # Example: Log some predictions
    for i in range(10):
        monitor.log_prediction(
            application_id=f"APP{i:06d}",
            features={
                'loan_amount': 5000000,
                'monthly_income': 500000,
                'age': 35
            },
            prediction=0,
            probability=0.23
        )

    # Get statistics
    stats = monitor.calculate_prediction_statistics()

    logger.info("\nProduction Statistics:")
    logger.info(f"Total predictions: {stats.get('total_predictions', 0)}")
    logger.info(f"Default rate: {stats.get('prediction_distribution', {}).get('default_rate', 0):.2%}")


if __name__ == "__main__":
    main()
```

```python
"""
Monitoring and drift detection API endpoints.
"""

from fastapi import APIRouter, HTTPException
from pathlib import Path
import pandas as pd
import json

from src.monitoring.drift_detector import DriftDetector, save_drift_report
from src.monitoring.monitor import ProductionMonitor
from src.utils.logger import logger

router = APIRouter(prefix="/api/v1/monitoring", tags=["Monitoring"])


@router.get("/health")
async def monitoring_health():
    """
    Check monitoring system health.
    """
    monitor = ProductionMonitor()

    return {
        "status": "healthy",
        "predictions_logged": monitor.predictions_file.exists(),
        "drift_reports_available": len(list(Path("data/monitoring").glob("drift_report_*.json"))) > 0
    }


@router.get("/stats")
async def get_production_stats():
    """
    Get production prediction statistics.
    """
    monitor = ProductionMonitor()
    stats = monitor.calculate_prediction_statistics()

    if not stats:
        raise HTTPException(
            status_code=404,
            detail="No production predictions logged yet"
        )

    return stats


@router.post("/check-drift")
async def check_drift():
    """
    Run drift detection on recent production data.

    Compares last 1000 production predictions against training data.
    """
    logger.info("Running drift detection...")

    # Get recent predictions
    monitor = ProductionMonitor()
    recent_data = monitor.get_recent_predictions(n=1000)

    if recent_data.empty:
        raise HTTPException(
            status_code=404,
            detail="No production data available for drift detection"
        )

    # Detect drift
    detector = DriftDetector()

    try:
        results = detector.detect_dataset_drift(recent_data)

        # Save report
        save_drift_report(results)

        return {
            "status": "completed",
            "total_features": results['total_features'],
            "features_with_drift": results['features_with_drift'],
            "drift_percentage": results['drift_percentage'],
            "alert": results['drift_percentage'] > 20,  # Alert if >20% drift
            "details": results['feature_results'][:10]  # Top 10 for brevity
        }

    except Exception as e:
        logger.error(f"Drift detection error: {e}")
        raise HTTPException(
            status_code=500,
            detail=f"Drift detection failed: {str(e)}"
        )


@router.get("/drift-reports")
async def list_drift_reports():
    """
    List all available drift reports.
    """
    reports_dir = Path("data/monitoring")

    if not reports_dir.exists():
        raise HTTPException(
            status_code=404,
            detail="No drift reports found"
        )

    report_files = list(reports_dir.glob("drift_report_*.json"))

    reports = []
    for file in sorted(report_files, reverse=True)[:10]:  # Last 10 reports
        with open(file, 'r') as f:
            data = json.load(f)

        reports.append({
            "filename": file.name,
            "timestamp": data.get('timestamp'),
            "features_with_drift": data.get('features_with_drift', 0),
            "drift_percentage": data.get('drift_percentage', 0)
        })

    return {
        "total_reports": len(report_files),
        "recent_reports": reports
    }


@router.get("/drift-report/{filename}")
async def get_drift_report(filename: str):
    """
    Get detailed drift report by filename.
    """
    report_file = Path("data/monitoring") / filename

    if not report_file.exists():
        raise HTTPException(
            status_code=404,
            detail=f"Report not found: {filename}"
        )

    with open(report_file, 'r') as f:
        report = json.load(f)

    return report
```

```python
"""
Generate data for monitoring dashboard.
"""

import pandas as pd
from pathlib import Path

def generate_dashboard_data():
    """
    Generate summary data for monitoring dashboard.
    """

    stats = monitor.calculate_prediction_statistics()

    with open(output_file, 'w') as f:
        json.dump(dashboard_data, f, indent=2)

    logger.info(f"Dashboard data saved to {output_file}")

    return dashboard_data


if __name__ == "__main__":
    data = generate_dashboard_data()
    print(json.dumps(data, indent=2))
```

## Understanding Statistical Tests

**Kolmogorov-Smirnov (KS) Test:**
```
H0: Both samples from same distribution
H1: Samples from different distributions

p-value < 0.05 → Reject H0 → Drift detected
p-value > 0.05 → Accept H0 → No drift
```

**Example:**
- Training: loan_amount mean = ₦5M
- Production: loan_amount mean = ₦8M
- KS test: p-value = 0.001 → DRIFT DETECTED

**Chi-Square Test:**
- For categories (employment status, state, etc.)
- Compares frequency distributions
- Same p-value interpretation

## When to Retrain Your Model

**Drift indicators:**
- ⚠️ >20% of features show drift
- ⚠️ Prediction distribution shifted significantly
- ⚠️ Default rate changed by >10 percentage points
- ⚠️ Performance metrics dropped >5%

**Actions:**
1. Investigate cause of drift
2. Check data quality
3. Retrain model on recent data
4. A/B test new model vs old
5. Deploy if performance improved

## Troubleshooting

**Issue:** "Reference data not found"
**Solution:** Run preprocessing first: `python src/data/preprocessor.py`

**Issue:** All features show drift
**Solution:** Check data quality, ensure same preprocessing

**Issue:** No drift detected (in production)
**Solution:** Normal if data distribution is stable

**Issue:** Chi-square test fails
**Solution:** Ensure enough samples in each category
