# Day 019: A/B Testing Framework

**Estimated Time:** 1.5-2 hours

## Goal
Build a production-ready A/B testing framework that allows you to safely compare different model versions in production by splitting traffic, collecting performance metrics, and automatically determining the winning variant using statistical significance testing.

---

## Why A/B Testing for ML Models?

When you have a new model version, you face a dilemma:
- **Switch immediately**: Risky - new model might perform worse in production
- **Test offline**: Not reliable - production data often differs from test data
- **Canary deploy**: Better, but manual and subjective

**A/B Testing** solves this by:
- Running both models simultaneously in production
- Randomly assigning users/requests to each variant
- Collecting real performance metrics
- Using statistical tests to determine significance
- Automatically promoting the winner

**Real-World Example:**
- **Variant A**: Current XGBoost model (ROC-AUC 0.916)
- **Variant B**: New ensemble model (ROC-AUC 0.931 in testing)
- **Question**: Will B perform better in production?
- **Solution**: Run A/B test with 50/50 traffic split for 7 days

```python
"""
A/B Testing Configuration
Defines test settings and statistical thresholds
"""
from pydantic import BaseSettings
from typing import List


class ABTestConfig(BaseSettings):
    """Configuration for A/B testing"""

    # Statistical significance
    SIGNIFICANCE_LEVEL: float = 0.05  # Alpha (5%)
    MINIMUM_SAMPLE_SIZE: int = 1000   # Min samples per variant
    MINIMUM_TEST_DURATION_HOURS: int = 24  # Min test duration

    # Traffic allocation
    DEFAULT_TRAFFIC_SPLIT: float = 0.5  # 50/50 split
    ENABLE_TRAFFIC_RAMPING: bool = True  # Gradual rollout

    # Automatic winner selection
    AUTO_PROMOTE_WINNER: bool = False  # Manual approval by default
    REQUIRED_IMPROVEMENT: float = 0.01  # Min 1% improvement

    # Metrics to track
    PRIMARY_METRIC: str = "roc_auc"
    SECONDARY_METRICS: List[str] = ["accuracy", "f1_score", "precision", "recall"]

    # Early stopping
    ENABLE_EARLY_STOPPING: bool = True
    EARLY_STOP_CONFIDENCE: float = 0.99  # 99% confidence for early stop

    class Config:
        env_file = ".env"
        case_sensitive = True


# Global config instance
ab_test_config = ABTestConfig()
```

**Key Concepts:**

1. **Significance Level (α)**: Probability of false positive (default 5%)
   - Lower α = more conservative, harder to detect real differences
   - Higher α = more liberal, easier to declare winner but higher false positive rate

2. **Minimum Sample Size**: Prevents premature conclusions from insufficient data

3. **Traffic Split**: Percentage of traffic to each variant (can be uneven)

4. **Early Stopping**: End test early if winner is clear with high confidence

```python
"""
A/B Test Manager
Creates, manages, and analyzes A/B tests
"""
import random
import hashlib
from datetime import datetime, timedelta
from typing import Dict, Any, Optional, List
from sqlalchemy.orm import Session

from src.ab_testing.config import ab_test_config
from src.models.database_models import ABTest, ABTestAssignment, ABTestMetrics
from src.utils.logger import get_logger


logger = get_logger(__name__)


class ABTestManager:
    """Manages A/B tests lifecycle"""

    def __init__(self, db: Session):
        self.db = db
        self.config = ab_test_config

    def create_test(
        self,
        name: str,
        description: str,
        variant_a_version: str,
        variant_b_version: str,
        traffic_split: float = None,
        duration_hours: int = None
    ) -> ABTest:
        """
        Create a new A/B test

        Args:
            name: Test name
            description: Test description
            variant_a_version: Control model version
            variant_b_version: Treatment model version
            traffic_split: Traffic to variant B (0.0-1.0)
            duration_hours: Test duration in hours

        Returns:
            ABTest object
        """
        if traffic_split is None:
            traffic_split = self.config.DEFAULT_TRAFFIC_SPLIT

        if duration_hours is None:
            duration_hours = self.config.MINIMUM_TEST_DURATION_HOURS

        # Create test record
        ab_test = ABTest(
            name=name,
            description=description,
            variant_a_version=variant_a_version,
            variant_b_version=variant_b_version,
            traffic_split=traffic_split,
            status="active",
            started_at=datetime.utcnow(),
            planned_end_at=datetime.utcnow() + timedelta(hours=duration_hours)
        )

        self.db.add(ab_test)
        self.db.commit()
        self.db.refresh(ab_test)

        logger.info(f"Created A/B test: {name} (ID: {ab_test.id})")
        return ab_test

    def assign_variant(
        self,
        test_id: int,
        user_id: Optional[int] = None,
        request_id: Optional[str] = None
    ) -> str:
        """
        Assign a user/request to a variant

        Uses consistent hashing for user_id (same user always gets same variant)
        Uses random for request_id (each request independent)

        Args:
            test_id: A/B test ID
            user_id: User ID (for consistent assignment)
            request_id: Request ID (for random assignment)

        Returns:
            Variant name ('variant_a' or 'variant_b')
        """
        ab_test = self.db.query(ABTest).filter(ABTest.id == test_id).first()

        if not ab_test or ab_test.status != "active":
            # Default to variant A if test not active
            return "variant_a"

        # Determine variant
        if user_id is not None:
            # Consistent hashing for users
            hash_input = f"{test_id}_{user_id}"
            hash_value = int(hashlib.md5(hash_input.encode()).hexdigest(), 16)
            assignment_value = (hash_value % 100) / 100.0
        else:
            # Random for anonymous requests
            assignment_value = random.random()

        variant = "variant_b" if assignment_value < ab_test.traffic_split else "variant_a"

        # Record assignment
        assignment = ABTestAssignment(
            test_id=test_id,
            user_id=user_id,
            request_id=request_id,
            variant=variant,
            assigned_at=datetime.utcnow()
        )
        self.db.add(assignment)
        self.db.commit()

        return variant

    def get_variant_version(self, test_id: int, variant: str) -> str:
        """Get model version for a variant"""
        ab_test = self.db.query(ABTest).filter(ABTest.id == test_id).first()

        if not ab_test:
            return None

        return (
            ab_test.variant_a_version if variant == "variant_a"
            else ab_test.variant_b_version
        )

    def record_prediction(
        self,
        test_id: int,
        variant: str,
        prediction: float,
        features: Dict[str, Any],
        actual_outcome: Optional[int] = None
    ):
        """Record a prediction for metrics collection"""
        metric = ABTestMetrics(
            test_id=test_id,
            variant=variant,
            prediction=prediction,
            features=features,
            actual_outcome=actual_outcome,
            recorded_at=datetime.utcnow()
        )
        self.db.add(metric)
        self.db.commit()

    def list_active_tests(self) -> List[ABTest]:
        """List all active A/B tests"""
        return self.db.query(ABTest).filter(ABTest.status == "active").all()

    def get_test(self, test_id: int) -> Optional[ABTest]:
        """Get a specific A/B test"""
        return self.db.query(ABTest).filter(ABTest.id == test_id).first()

    def stop_test(self, test_id: int, reason: str = "Manual stop"):
        """Stop an active A/B test"""
        ab_test = self.db.query(ABTest).filter(ABTest.id == test_id).first()

        if not ab_test:
            raise ValueError(f"Test {test_id} not found")

        ab_test.status = "stopped"
        ab_test.ended_at = datetime.utcnow()
        ab_test.stop_reason = reason

        self.db.commit()
        logger.info(f"Stopped A/B test {test_id}: {reason}")

    def complete_test(self, test_id: int, winner: str, confidence: float):
        """Mark test as completed with winner"""
        ab_test = self.db.query(ABTest).filter(ABTest.id == test_id).first()

        if not ab_test:
            raise ValueError(f"Test {test_id} not found")

        ab_test.status = "completed"
        ab_test.ended_at = datetime.utcnow()
        ab_test.winner = winner
        ab_test.winner_confidence = confidence

        self.db.commit()
        logger.info(f"Completed A/B test {test_id}: Winner = {winner} ({confidence:.2%})")
```

**Key Concepts:**

1. **Consistent Hashing**: Same user always gets same variant (important for user experience)

2. **Traffic Split**: `traffic_split=0.3` means 30% to variant B, 70% to variant A

3. **Assignment Logging**: Every assignment recorded for audit trail

4. **Test Lifecycle**: active → stopped/completed

```python
"""
Statistical Analysis for A/B Tests
Calculates significance and determines winners
"""
import numpy as np
from scipy import stats
from typing import Dict, Any, Tuple
from sqlalchemy.orm import Session

from src.ab_testing.config import ab_test_config
from src.models.database_models import ABTestMetrics
from src.utils.logger import get_logger


logger = get_logger(__name__)


class StatisticalAnalyzer:
    """Statistical analysis for A/B test results"""

    def __init__(self, db: Session):
        self.db = db
        self.config = ab_test_config

    def analyze_test(self, test_id: int) -> Dict[str, Any]:
        """
        Perform complete statistical analysis of A/B test

        Returns:
            Analysis results with significance tests
        """
        # Get metrics for both variants
        variant_a_metrics = self._get_variant_metrics(test_id, "variant_a")
        variant_b_metrics = self._get_variant_metrics(test_id, "variant_b")

        # Calculate performance metrics
        variant_a_performance = self._calculate_performance(variant_a_metrics)
        variant_b_performance = self._calculate_performance(variant_b_metrics)

        # Check minimum sample size
        if (variant_a_performance["sample_size"] < self.config.MINIMUM_SAMPLE_SIZE or
            variant_b_performance["sample_size"] < self.config.MINIMUM_SAMPLE_SIZE):
            return {
                "sufficient_data": False,
                "message": "Insufficient samples for statistical significance",
                "variant_a": variant_a_performance,
                "variant_b": variant_b_performance
            }

        # Perform significance tests
        significance_tests = self._perform_significance_tests(
            variant_a_metrics,
            variant_b_metrics,
            variant_a_performance,
            variant_b_performance
        )

        # Determine winner
        winner_analysis = self._determine_winner(
            variant_a_performance,
            variant_b_performance,
            significance_tests
        )

        return {
            "sufficient_data": True,
            "variant_a": variant_a_performance,
            "variant_b": variant_b_performance,
            "significance_tests": significance_tests,
            "winner": winner_analysis
        }

    def _get_variant_metrics(self, test_id: int, variant: str) -> list:
        """Get all metrics for a variant"""
        metrics = self.db.query(ABTestMetrics).filter(
            ABTestMetrics.test_id == test_id,
            ABTestMetrics.variant == variant,
            ABTestMetrics.actual_outcome.isnot(None)  # Only labeled data
        ).all()

        return metrics

    def _calculate_performance(self, metrics: list) -> Dict[str, Any]:
        """Calculate performance metrics from predictions"""
        if not metrics:
            return {
                "sample_size": 0,
                "roc_auc": 0,
                "accuracy": 0,
                "f1_score": 0,
                "precision": 0,
                "recall": 0
            }

        # Extract predictions and actuals
        y_true = [m.actual_outcome for m in metrics]
        y_pred_proba = [m.prediction for m in metrics]
        y_pred = [1 if p >= 0.5 else 0 for p in y_pred_proba]

        # Calculate metrics
        from sklearn.metrics import (
            roc_auc_score, accuracy_score, f1_score,
            precision_score, recall_score
        )

        return {
            "sample_size": len(metrics),
            "roc_auc": roc_auc_score(y_true, y_pred_proba),
            "accuracy": accuracy_score(y_true, y_pred),
            "f1_score": f1_score(y_true, y_pred, zero_division=0),
            "precision": precision_score(y_true, y_pred, zero_division=0),
            "recall": recall_score(y_true, y_pred, zero_division=0)
        }

    def _perform_significance_tests(
        self,
        variant_a_metrics: list,
        variant_b_metrics: list,
        variant_a_performance: Dict,
        variant_b_performance: Dict
    ) -> Dict[str, Any]:
        """Perform statistical significance tests"""
        results = {}

        # Test 1: ROC-AUC comparison using bootstrap
        roc_auc_test = self._bootstrap_roc_auc_test(
            variant_a_metrics,
            variant_b_metrics
        )
        results["roc_auc"] = roc_auc_test

        # Test 2: Accuracy comparison using proportion z-test
        accuracy_test = self._proportion_z_test(
            variant_a_metrics,
            variant_b_metrics
        )
        results["accuracy"] = accuracy_test

        # Test 3: Conversion rate (default rate) comparison
        conversion_test = self._conversion_rate_test(
            variant_a_metrics,
            variant_b_metrics
        )
        results["conversion_rate"] = conversion_test

        return results

    def _bootstrap_roc_auc_test(
        self,
        variant_a_metrics: list,
        variant_b_metrics: list,
        n_bootstrap: int = 1000
    ) -> Dict[str, Any]:
        """Bootstrap test for ROC-AUC difference"""
        from sklearn.metrics import roc_auc_score

        # Extract data
        y_true_a = np.array([m.actual_outcome for m in variant_a_metrics])
        y_pred_a = np.array([m.prediction for m in variant_a_metrics])

        y_true_b = np.array([m.actual_outcome for m in variant_b_metrics])
        y_pred_b = np.array([m.prediction for m in variant_b_metrics])

        # Bootstrap
        differences = []
        for _ in range(n_bootstrap):
            # Resample with replacement
            idx_a = np.random.choice(len(y_true_a), size=len(y_true_a), replace=True)
            idx_b = np.random.choice(len(y_true_b), size=len(y_true_b), replace=True)

            auc_a = roc_auc_score(y_true_a[idx_a], y_pred_a[idx_a])
            auc_b = roc_auc_score(y_true_b[idx_b], y_pred_b[idx_b])

            differences.append(auc_b - auc_a)

        differences = np.array(differences)

        # Calculate p-value (two-tailed)
        p_value = np.mean(np.abs(differences) >= np.abs(np.mean(differences)))

        # Calculate confidence interval
        ci_lower = np.percentile(differences, 2.5)
        ci_upper = np.percentile(differences, 97.5)

        return {
            "mean_difference": float(np.mean(differences)),
            "p_value": float(p_value),
            "significant": p_value < self.config.SIGNIFICANCE_LEVEL,
            "confidence_interval": [float(ci_lower), float(ci_upper)]
        }

    def _proportion_z_test(
        self,
        variant_a_metrics: list,
        variant_b_metrics: list
    ) -> Dict[str, Any]:
        """Z-test for proportion (accuracy) difference"""
        # Extract data
        y_true_a = np.array([m.actual_outcome for m in variant_a_metrics])
        y_pred_a = np.array([1 if m.prediction >= 0.5 else 0 for m in variant_a_metrics])

        y_true_b = np.array([m.actual_outcome for m in variant_b_metrics])
        y_pred_b = np.array([1 if m.prediction >= 0.5 else 0 for m in variant_b_metrics])

        # Calculate proportions
        n_a = len(y_true_a)
        n_b = len(y_true_b)
        correct_a = np.sum(y_true_a == y_pred_a)
        correct_b = np.sum(y_true_b == y_pred_b)

        p_a = correct_a / n_a
        p_b = correct_b / n_b

        # Pooled proportion
        p_pooled = (correct_a + correct_b) / (n_a + n_b)

        # Standard error
        se = np.sqrt(p_pooled * (1 - p_pooled) * (1/n_a + 1/n_b))

        # Z-statistic
        z_stat = (p_b - p_a) / se

        # P-value (two-tailed)
        p_value = 2 * (1 - stats.norm.cdf(abs(z_stat)))

        return {
            "z_statistic": float(z_stat),
            "p_value": float(p_value),
            "significant": p_value < self.config.SIGNIFICANCE_LEVEL,
            "proportion_a": float(p_a),
            "proportion_b": float(p_b),
            "difference": float(p_b - p_a)
        }

    def _conversion_rate_test(
        self,
        variant_a_metrics: list,
        variant_b_metrics: list
    ) -> Dict[str, Any]:
        """Test for conversion rate (default rate) difference"""
        # Calculate default rates
        defaults_a = sum(1 for m in variant_a_metrics if m.actual_outcome == 1)
        defaults_b = sum(1 for m in variant_b_metrics if m.actual_outcome == 1)

        n_a = len(variant_a_metrics)
        n_b = len(variant_b_metrics)

        rate_a = defaults_a / n_a if n_a > 0 else 0
        rate_b = defaults_b / n_b if n_b > 0 else 0

        # Chi-square test
        observed = np.array([[defaults_a, n_a - defaults_a],
                           [defaults_b, n_b - defaults_b]])

        chi2, p_value, dof, expected = stats.chi2_contingency(observed)

        return {
            "chi_square": float(chi2),
            "p_value": float(p_value),
            "significant": p_value < self.config.SIGNIFICANCE_LEVEL,
            "rate_a": float(rate_a),
            "rate_b": float(rate_b),
            "difference": float(rate_b - rate_a)
        }

    def _determine_winner(
        self,
        variant_a_performance: Dict,
        variant_b_performance: Dict,
        significance_tests: Dict
    ) -> Dict[str, Any]:
        """Determine the winning variant"""
        primary_metric = self.config.PRIMARY_METRIC

        # Get primary metric values
        metric_a = variant_a_performance[primary_metric]
        metric_b = variant_b_performance[primary_metric]

        # Check significance of primary metric
        primary_test = significance_tests.get(primary_metric, {})
        is_significant = primary_test.get("significant", False)

        # Determine winner
        if not is_significant:
            winner = "no_winner"
            confidence = 0.0
            reason = "No statistically significant difference"
        elif metric_b > metric_a:
            winner = "variant_b"
            confidence = 1.0 - primary_test["p_value"]
            reason = f"Variant B significantly better ({primary_metric})"
        else:
            winner = "variant_a"
            confidence = 1.0 - primary_test["p_value"]
            reason = f"Variant A significantly better ({primary_metric})"

        # Check minimum improvement threshold
        improvement = abs(metric_b - metric_a) / metric_a
        if improvement < self.config.REQUIRED_IMPROVEMENT:
            winner = "no_winner"
            reason = "Improvement below minimum threshold"

        return {
            "winner": winner,
            "confidence": confidence,
            "reason": reason,
            "metric_difference": metric_b - metric_a,
            "improvement_percentage": improvement * 100
        }
```

**Key Concepts:**

1. **Bootstrap Test**: Resampling method for ROC-AUC comparison (no parametric assumptions)

2. **Z-Test**: Tests if two proportions (accuracies) differ significantly

3. **Chi-Square Test**: Tests if conversion rates differ

4. **P-Value**: Probability of observing results if there's no real difference
   - p < 0.05 = significant (reject null hypothesis)
   - p ≥ 0.05 = not significant (can't reject null)

5. **Confidence**: 1 - p_value (higher = more certain about winner)

```python
"""
A/B Testing API Routes
Endpoints for managing A/B tests
"""
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session
from typing import Dict, Any, List
from pydantic import BaseModel

from src.utils.database import get_db
from src.utils.security import get_current_user
from src.ab_testing.ab_test_manager import ABTestManager
from src.ab_testing.statistical_analysis import StatisticalAnalyzer
from src.models.database_models import User


router = APIRouter(prefix="/api/v1/ab-testing", tags=["ab-testing"])


class CreateTestRequest(BaseModel):
    name: str
    description: str
    variant_a_version: str
    variant_b_version: str
    traffic_split: float = 0.5
    duration_hours: int = 168  # 1 week default


@router.post("/tests", response_model=Dict[str, Any])
async def create_ab_test(
    request: CreateTestRequest,
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user)
):

    manager = ABTestManager(db)

    ab_test = manager.create_test(
        name=request.name,
        description=request.description,
        variant_a_version=request.variant_a_version,
        variant_b_version=request.variant_b_version,
        traffic_split=request.traffic_split,
        duration_hours=request.duration_hours
    )

    return {
        "id": ab_test.id,
        "name": ab_test.name,
        "variant_a": ab_test.variant_a_version,
        "variant_b": ab_test.variant_b_version,
        "traffic_split": ab_test.traffic_split,
        "status": ab_test.status,
        "started_at": ab_test.started_at.isoformat()
    }

            "variant_b": test.variant_b_version,

            "started_at": test.started_at.isoformat()

    ]

    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user)

    test = manager.get_test(test_id)

    if not test:

    test_id: int,
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    """Complete A/B test and select winner"""
    # Analyze first
    analyzer = StatisticalAnalyzer(db)
    results = analyzer.analyze_test(test_id)

    if not results["sufficient_data"]:
        raise HTTPException(status_code=400, detail="Insufficient data for analysis")

    winner = results["winner"]["winner"]
    confidence = results["winner"]["confidence"]

    # Mark as completed
    manager = ABTestManager(db)
    manager.complete_test(test_id, winner, confidence)

    return {
        "status": "success",
        "test_id": test_id,
        "winner": winner,
        "confidence": confidence,
        "analysis": results
    }
```

## Common Issues & Solutions

### Issue 1: "Insufficient samples for statistical significance"
**Solution:** Normal - need 1000+ labeled samples per variant. In production, this accumulates over days/weeks.

### Issue 2: Variant Always Same for User
**Solution:** This is correct! Consistent hashing ensures same user gets same experience.

### Issue 3: "Test not found"
**Check:** Ensure test ID correct and test exists:
```bash
curl -X GET "http://localhost:8000/api/v1/ab-testing/tests" \
  -H "Authorization: Bearer $TOKEN"
```

### Issue 4: Analysis Shows No Winner
**Reason:** Either:
- Not enough samples
- No statistically significant difference
- Improvement below minimum threshold (1%)
