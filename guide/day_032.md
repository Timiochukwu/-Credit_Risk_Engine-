# Day 032: Helm Charts - Package Manager for Kubernetes

**Estimated Time:** 2 hours

## Goal
Master Helm, the package manager for Kubernetes, to simplify deployment and management of the Credit Risk Engine. Create a Helm chart with templating, values files for different environments, and learn release management including upgrades and rollbacks.

---

## Why Helm?

**Problems with Raw Kubernetes YAML:**
- Repetitive YAML for each environment
- No versioning of deployments
- Difficult to manage complex applications
- Hard to parameterize configurations
- No easy rollback mechanism
- Manual dependency management

**Helm Benefits:**
- **Templating**: Reuse YAML with variables
- **Packaging**: Bundle all resources together
- **Versioning**: Track release history
- **Rollback**: Easy revert to previous version
- **Repository**: Share charts
- **Dependency Management**: Install dependencies automatically

**Example:**
```
Without Helm: 20+ YAML files × 3 environments = 60 files
With Helm: 1 chart + 3 values files = 4 files
```

---

## Key Concepts

### Helm Architecture

```
Chart (package)
├── templates/       # Kubernetes YAML templates
├── values.yaml      # Default values
├── Chart.yaml       # Chart metadata
└── charts/          # Dependencies
```

### Components

1. **Chart**: Package of Kubernetes resources
2. **Release**: Installed instance of a chart
3. **Repository**: Storage for charts
4. **Values**: Configuration parameters
5. **Templates**: Parameterized YAML files

## File 4: Deployment Template

**File:** `helm/credit-risk-chart/templates/deployment.yaml`

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ include "credit-risk-engine.fullname" . }}
  labels:
    {{- include "credit-risk-engine.labels" . | nindent 4 }}
spec:
  {{- if not .Values.autoscaling.enabled }}
  replicas: {{ .Values.replicaCount }}
  {{- end }}
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
  selector:
    matchLabels:
      {{- include "credit-risk-engine.selectorLabels" . | nindent 6 }}
  template:
    metadata:
      annotations:
        checksum/config: {{ include (print $.Template.BasePath "/configmap.yaml") . | sha256sum }}
        {{- with .Values.podAnnotations }}
        {{- toYaml . | nindent 8 }}
        {{- end }}
      labels:
        {{- include "credit-risk-engine.selectorLabels" . | nindent 8 }}
    spec:
      {{- with .Values.imagePullSecrets }}
      imagePullSecrets:
        {{- toYaml . | nindent 8 }}
      {{- end }}
      serviceAccountName: {{ include "credit-risk-engine.serviceAccountName" . }}
      securityContext:
        {{- toYaml .Values.podSecurityContext | nindent 8 }}
      {{- if .Values.initContainers.runMigrations }}
      initContainers:
      - name: run-migrations
        image: "{{ .Values.image.repository }}:{{ .Values.image.tag | default .Chart.AppVersion }}"
        command: ['alembic', 'upgrade', 'head']
        env:
        - name: DATABASE_URL
          valueFrom:
            secretKeyRef:
              name: {{ include "credit-risk-engine.fullname" . }}-secrets
              key: database-url
      {{- end }}
      containers:
      - name: {{ .Chart.Name }}
        securityContext:
          {{- toYaml .Values.securityContext | nindent 12 }}
        image: "{{ .Values.image.repository }}:{{ .Values.image.tag | default .Chart.AppVersion }}"
        imagePullPolicy: {{ .Values.image.pullPolicy }}
        ports:
        - name: http
          containerPort: 8000
          protocol: TCP
        envFrom:
        - configMapRef:
            name: {{ include "credit-risk-engine.fullname" . }}-config
        env:
        - name: SECRET_KEY
          valueFrom:
            secretKeyRef:
              name: {{ include "credit-risk-engine.fullname" . }}-secrets
              key: secret-key
        - name: DATABASE_URL
          valueFrom:
            secretKeyRef:
              name: {{ include "credit-risk-engine.fullname" . }}-secrets
              key: database-url
        livenessProbe:
          {{- toYaml .Values.livenessProbe | nindent 12 }}
        readinessProbe:
          {{- toYaml .Values.readinessProbe | nindent 12 }}
        resources:
          {{- toYaml .Values.resources | nindent 12 }}
        {{- if .Values.persistence.enabled }}
        volumeMounts:
        - name: model-storage
          mountPath: /app/models
        {{- end }}
      {{- if .Values.persistence.enabled }}
      volumes:
      - name: model-storage
        persistentVolumeClaim:
          claimName: {{ include "credit-risk-engine.fullname" . }}-pvc
      {{- end }}
      {{- with .Values.nodeSelector }}
      nodeSelector:
        {{- toYaml . | nindent 8 }}
      {{- end }}
      {{- with .Values.affinity }}
      affinity:
        {{- toYaml . | nindent 8 }}
      {{- end }}
      {{- with .Values.tolerations }}
      tolerations:
        {{- toYaml . | nindent 8 }}
      {{- end }}
```

## File 8: Helpers Template

**File:** `helm/credit-risk-chart/templates/_helpers.tpl`

```yaml
{{/*
Expand the name of the chart.
*/}}
{{- define "credit-risk-engine.name" -}}
{{- default .Chart.Name .Values.nameOverride | trunc 63 | trimSuffix "-" }}
{{- end }}

{{/*
Create a default fully qualified app name.
*/}}
{{- define "credit-risk-engine.fullname" -}}
{{- if .Values.fullnameOverride }}
{{- .Values.fullnameOverride | trunc 63 | trimSuffix "-" }}
{{- else }}
{{- $name := default .Chart.Name .Values.nameOverride }}
{{- if contains $name .Release.Name }}
{{- .Release.Name | trunc 63 | trimSuffix "-" }}
{{- else }}
{{- printf "%s-%s" .Release.Name $name | trunc 63 | trimSuffix "-" }}
{{- end }}
{{- end }}
{{- end }}

{{/*
Create chart name and version as used by the chart label.
*/}}
{{- define "credit-risk-engine.chart" -}}
{{- printf "%s-%s" .Chart.Name .Chart.Version | replace "+" "_" | trunc 63 | trimSuffix "-" }}
{{- end }}

{{/*
Common labels
*/}}
{{- define "credit-risk-engine.labels" -}}
helm.sh/chart: {{ include "credit-risk-engine.chart" . }}
{{ include "credit-risk-engine.selectorLabels" . }}
{{- if .Chart.AppVersion }}
app.kubernetes.io/version: {{ .Chart.AppVersion | quote }}
{{- end }}
app.kubernetes.io/managed-by: {{ .Release.Service }}
{{- end }}

{{/*
Selector labels
*/}}
{{- define "credit-risk-engine.selectorLabels" -}}
app.kubernetes.io/name: {{ include "credit-risk-engine.name" . }}
app.kubernetes.io/instance: {{ .Release.Name }}
{{- end }}

{{/*
Create the name of the service account to use
*/}}
{{- define "credit-risk-engine.serviceAccountName" -}}
{{- if .Values.serviceAccount.create }}
{{- default (include "credit-risk-engine.fullname" .) .Values.serviceAccount.name }}
{{- else }}
{{- default "default" .Values.serviceAccount.name }}
{{- end }}
{{- end }}
```

## Using Helm

### Install Chart

```bash
# Add dependency repositories
helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo update

# Install chart
helm install credit-risk ./helm/credit-risk-chart \
  --namespace credit-risk \
  --create-namespace \
  --set secrets.secretKey="your-secret-key" \
  --set secrets.databaseUrl="postgresql://user:pass@db/dbname"

# Install with specific values file
helm install credit-risk ./helm/credit-risk-chart \
  --namespace credit-risk \
  --values ./helm/credit-risk-chart/values-production.yaml
```

### Upgrade Release

```bash
# Upgrade to new version
helm upgrade credit-risk ./helm/credit-risk-chart \
  --namespace credit-risk \
  --set image.tag="v1.1.0"

# Upgrade with new values
helm upgrade credit-risk ./helm/credit-risk-chart \
  --namespace credit-risk \
  --values values-production.yaml \
  --reuse-values
```

### Rollback

```bash
# List releases
helm list -n credit-risk

# Show history
helm history credit-risk -n credit-risk

# Rollback to previous version
helm rollback credit-risk -n credit-risk

# Rollback to specific revision
helm rollback credit-risk 2 -n credit-risk
```

### Uninstall

```bash
helm uninstall credit-risk -n credit-risk
```

### Lint Chart

```bash
helm lint ./helm/credit-risk-chart
```

### Dry Run

```bash
helm install credit-risk ./helm/credit-risk-chart \
  --dry-run \
  --debug \
  --namespace credit-risk
```

### Template Rendering

```bash
# Render templates
helm template credit-risk ./helm/credit-risk-chart \
  --namespace credit-risk \
  --values values-production.yaml > rendered.yaml

# Inspect
cat rendered.yaml
```
